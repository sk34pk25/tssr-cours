    PowerShell : langage objet

    Les objets : méthodes

    • Les objets disposent également de méthodes parfois communes à plusieurs
    types d’objets.
    • Contrairement aux propriétés, les méthodes effectuent des actions sur la
    totalité de l’objet ou sur la valeur d’une ou plusieurs propriétés d’un objet.

    L’objet 
«system.datetime» 
peut être employé avec 
plusieurs méthodes.

    13

    13

    PowerShell : langage objet

    Les objets : méthodes

    • Pour appliquer une méthode, on utilise la commande permettant d’obtenir un
    objet.

    PS > Get-Date

    • On encadre la commande avec des parenthèses afin d’appliquer la méthode. On
    ajoute la méthode précédée d’un point de concaténation, puis à la suite de la
    méthode on ajoute entre parenthèses la valeur nécessaire à la méthode.

    PS > (Get-Date).AddDays(*)
    • Ici la méthode AddDays ajoute un jour de plus à l’objet System.DateTime
renvoyé par la commande Get-date.

    Get-Member

    Démonstration 01 du module 2 

    L’objectif de cette démonstration est de présenter la commande Get-Member qui permet de 
visualiser les informations d’un objet PowerShell.

    Déroulement 

    • 
Toute commande PowerShell agit sur un objet du système Windows. La commande Get-member 
permet de connaître trois informations fondamentales sur l’objet en cours. 
    On obtient le type d’objet Paramètre TypeName. 
    La colonne MemberType renseigne sur les méthodes et les propriétés qui composent notre objet. 
    La commande Get-Member fait partie des trois commandes dites clés pour utiliser PowerShell

    Les propriétés

    Démonstration 02 du module 2

    L’objectif de cette démonstration est de vous présenter les propriétés.

    Déroulement

    Chaque objet PowerShell contient des propriétés. La liste de ses propriétés est définie par le type
    d’objet auquel il appartient. 

    • 
Le type de propriétés est indiqué par la commande Get-Member dans la colonne Definition.

    •
    Connaître le type de propriété est essentiel pour pouvoir la manipuler. 

    La propriété Description est de type String ; elle n’accepte donc que les chaînes de 
caractères. 
    La propriété PasswordRequired est type Bool ; elle n’accepte que les valeurs de type booléen.

    Pour modifier les valeurs d’une propriété, on va dans un premier temps choisir l’objet sur lequel on
    souhaite modifier la valeur de la propriété.

    Les méthodes

    Démonstration 03 du module 2

    L’objectif de cette démonstration est de vous présenter ce que sont les méthodes.

    Déroulement

    De la même façon qu’un objet contient des propriétés, les méthodes qu’il contient vont permettre
    d’effectuer des actions sur la totalité de l’objet, sur une propriété ou de faire des actions de
    conversion par exemple. 

    • 
Les méthodes sont révélées par la commande Get-Member.

    •
    Les méthodes sont des actions à la différence des propriétés qui, elles, sont statiques. 

    La méthode Start a une portée sur tout l’objet service.

    L’utilisation d’une méthode se fait en ayant les informations à disposition telles que l’objet sur lequel
    on souhaite exécuter la méthode ou la propriété de l’objet sur laquelle on va exécuter cette
    méthode.

Les schémas de synthèse de cette fiche sont des illustrations IA / externes au cours, sauf les captures explicitement attribuées à un document source.

    Objectifs¶

    À l'issue de ce module, vous devez pouvoir reconnaître un objet PowerShell, repérer ses membres et distinguer ses propriétés de ses méthodes. Le TP utilise des objets de service, d'utilisateur local et de date dans un environnement de laboratoire.

    PowerShell : un langage orienté objet¶

    Le support présente PowerShell comme un langage orienté objet. Un objet est défini par un ensemble de propriétés et de méthodes. Les exemples du module utilisent notamment les objets retournés par Get-Service, Get-LocalUser et Get-Date.

    Les objets observés, leurs membres et les résultats affichés dépendent de l'environnement historique du laboratoire. Ils servent ici d'exemples du support, pas d'inventaire universel.

    Examiner les membres avec Get-Member¶

    Get-Member permet de visualiser les informations d'un objet PowerShell. Les sources mettent en avant les colonnes suivantes :

    • TypeName : le type de l'objet traité ;
    • MemberType : la nature du membre affiché ;
    • Definition : la définition connue du membre.
    Get-Service | Get-Member
Get-LocalUser | Get-Member
Get-Date | Get-Member

    Formulation du support — NEEDS_REVIEW

    Le support affirme que Get-Member s'utilise exclusivement après une commande dont le verbe est Get. Cette formulation est conservée comme indication documentaire du support ; elle n'est pas présentée ici comme une règle universelle.

    La démonstration rappelle également les commandes suivantes, déjà utilisées dans le parcours, pour rechercher une commande puis consulter son aide :

    Get-Command -name *-service
Get-Help Get-Command

    Propriétés et valeurs¶

    Les propriétés d'un objet sont définies par son type. Le support indique que leurs valeurs peuvent avoir différents types : String, Int, Bool, Array et Object.

    Dans le TP, l'observation des propriétés d'un service passe notamment par :

    Get-Service -Name Spooler | Get-Member -MemberType Property
Get-Service -Name Spooler

    Les noms de comptes, valeurs de propriétés et sorties propres au laboratoire ne sont pas publiés. Utilisez les valeurs fournies dans l'environnement de formation lorsque le TP les demande.

    Formes documentaires à conserver

    Certaines démonstrations emploient -ServiceName, alors que la correction emploie -Name. Cette divergence est documentée dans la correction du TP et n'est pas harmonisée silencieusement.

    Méthodes¶

    Le support distingue les méthodes des propriétés : les méthodes réalisent des actions sur l'objet, sur la valeur d'une ou plusieurs propriétés, ou des conversions. Les propriétés sont, elles, décrites comme « statiques » dans la démonstration.

    Pour appliquer une méthode, les sources encadrent la commande qui retourne l'objet, ajoutent un point puis la méthode et ses parenthèses :

    (get-date).adddays(1)
(Get-Service -Name Spooler).stop()

    La seconde commande appartient au scénario du TP : elle modifie l'état du service ciblé. Les états, dates et membres affichés dans les captures sont des observations historiques ou dynamiques de laboratoire.

    Vérifications issues du TP¶

    • identifier le type, les propriétés et les méthodes affichés pour l'objet demandé ;
    • relever les propriétés et les valeurs observées dans le scénario ;
    • vérifier l'état du service après l'appel de la méthode demandée ;
    • contrôler une date d'expiration de compte après la mise à jour demandée, avec les identifiants fournis dans le laboratoire.

    Synthèse¶

    M02 introduit l'objet PowerShell par ses propriétés, ses méthodes, son type et la lecture de ses membres avec Get-Member. Les objets de service, d'utilisateur local et de date servent de supports de pratique source-faithful dans le TP unique « L'objet ».

    Mettre en pratique¶

    Le TP 01 « L'objet », son énoncé, sa correction et la fiche de révision sont proposés séparément dans l'écosystème du module. Ils ne font pas partie de cette proposition de page de cours.
