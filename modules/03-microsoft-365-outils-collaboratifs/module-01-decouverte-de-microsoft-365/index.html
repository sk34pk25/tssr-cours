    Importance : socle de la progression officielle

    Périmètre et versions

    Les interfaces et les licences Microsoft 365 évoluent régulièrement. « Office 365 ProPlus » est l’ancien nom de « Microsoft 365 Apps for enterprise » ; les chemins d’écran sont à rapprocher de la version disponible dans le tenant utilisé. Référence : Cycle de vie Microsoft 365 Apps.

    Objectifs et compétences¶

    • Comprendre le modèle SaaS et les enjeux du cloud.
    • Identifier les principaux services Microsoft 365.
    • Distinguer plans, licences et applications clientes.
    • Reconnaître les prérequis d’une plateforme collaborative.

    Façon simple de le comprendre

    Ce module sert à passer de la notion « Découverte de Microsoft 365 » à une méthode que l’on peut expliquer, appliquer, vérifier et dépanner.

    Méthode de travail¶

    1. Lire les concepts dans l’ordre du support.
    2. Reproduire les exemples dans un environnement de laboratoire.
    3. Noter le résultat attendu avant de modifier une configuration.
    4. Vérifier avec l’outil ou la commande appropriée.
    5. Revenir à l’état initial si le résultat diverge.

    Vue d’ensemble de la plateforme¶

    flowchart TB U["Identité de l’utilisateur"] --> L["Licence Microsoft 365"] L --> A["Applications clientes<br/>Word · Excel · Outlook"] L --> C["Services cloud"] C --> EX["Exchange Online<br/>messagerie et calendrier"] C --> SP["SharePoint Online<br/>sites et contenus partagés"] C --> OD["OneDrive<br/>fichiers personnels synchronisés"] C --> TE["Teams<br/>conversations et réunions"] TE --> SP TE --> EX

    La licence ouvre un ensemble cohérent de services : Teams s’appuie notamment sur SharePoint pour les fichiers d’équipe et sur Exchange pour certaines fonctions de calendrier et de messagerie.
