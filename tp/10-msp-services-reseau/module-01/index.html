    Énoncé

    1. Présentation et préparation de l'infrastructure

    Le cœur de métier de la société "Support-Terre" est de proposer du support informatique
    personnalisé pour les PME.


    Vous intégrez l'équipe technique du projet "TSSRC-Série-EU". Votre objectif est de
    maquetter une infrastructure en respectant les contraintes imposées par l'équipe
    architecture du projet.

    Prérequis

    •
    Disposer d'images ISO (Windows Server, Debian, pfSense)

    •
    VMware Workstation doit être installé dans votre environnement de travail

    a. Présentation de l’infrastructure

    Le contexte d’infrastructure sur lequel vous travaillerez est organisé autour de 3 périmètres
    réseau :

    LAN Serveurs
    Réseau d’appartenance des serveurs / services mis en place
    pour les utilisateurs de l’entreprise

    LAN Clients
    Réseau d’appartenance des postes clients des utilisateurs

    WAN
    Réseau public, non géré par l’entreprise, destiné à fournir des
    services aux utilisateurs

    Vous aurez à gérer l’ensemble des machines présentes dans les réseaux LAN Serveurs et
    LAN Clients.

    b. Conception du plan d’adressage IPv4

    D correspond au dernier octet de l'adresse IP du poste de travail fourni par l'ENI

    •
    Un réseau 192.168.4xD.0 / 22 est attribué par stagiaire.

    Exemple :

    Le dernier octet de l'adresse IP du poste de travail fourni par l'ENI est
    13. 13x4=52. Le réseau qui m’est alloué est le 192.168.52.0 / 22

    •
    Ce réseau est segmenté en 4 sous réseaux, chacun ayant un masque de
    255.255.255.0 (/24)

    •
    Le premier sous réseau est utilisé pour adresser le LAN Clients

    •
    Le dernier sous réseau est utilisé pour adresser le LAN Serveurs

    •
    Le réseau du poste de travail fourni par l'ENI est utilisé pour adresser la machine de
    l’environnement étant sur le WAN.

    Reproduire le précédent schéma (ou équivalent) puis y reporter vos adresses de réseaux
    locaux Clients et Serveurs.

    c. Implémentation du routeur

    Installer une première machine virtuelle pfSense à partir d’une image ISO d’installation, elle
    possédera les caractéristiques suivantes :

    Nom
    ROUTEUR-XY (remplacer XY par vos initiales)

    Système d’exploitation
    pfSense

    Nombre de cartes réseau associées
    3

    À l’issue de l’installation, configurer le réseau en respectant les contraintes suivantes :

    •
    Sur les réseaux LAN Clients et Serveurs, ROUTEUR-XY utilisera la dernière adresse
    d’hôte utilisable

    •
    Sur le réseau global (accessible par l'interface WAN), votre routeur aura pour
    adresse : id_reseau.42.D

    Exemple :

    L'ID de réseau du poste de travail fourni par l'ENI est 10.3.0.0/16 et le
    dernier octet de l'adresse IP du poste de travail fourni par l'ENI est
    13.

    f. Routage et NAT

    Configuration de la passerelle par défaut


    Depuis l’interface web de votre pfSense, via les outils de diagnostic,
    vérifier que celui-ci communique bien avec la machine ayant l’adresse
    IPv4 : 9.9.9.9.


    Configurer l’adresse de votre pfSense comme adresse de passerelle par
    défaut sur les clients et sur les serveurs.


    Vérifier que les clients parviennent bien à communiquer avec les serveurs 

    o Au besoin vérifier / adapter la configuration des pare-feu des
