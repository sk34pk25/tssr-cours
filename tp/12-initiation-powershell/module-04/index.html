    Les variables

    Démonstration 01 du module 4

    L’objectif de cette démonstration est de découvrir en quoi, comme tout langage-objet,
    PowerShell utilise les variables qui permettent de stocker des données dans la mémoire vive de
    l’ordinateur puis de les réutiliser dans d’autre commande.

    Déroulement 

    • 
La console PowerShell dispose de variables réservées comme nous avons pu le voir avec 
$PSItem. Nous allons étudier les façons de travailler avec les variables. 
    • 
La commande Get-Variable permet de connaître toutes les variables disponibles 
actuellement dans la console PowerShell. 
    • 
Pour déclarer une nouvelle variable, on utilise le caractère $ suivi du symbole = puis de la valeur 
à attribuer à la variable. 
    Attention au type de variable ! Le fait d’attribuer la valeur 1 type la variable en INT.  
    Pour obtenir le type de variable, on utilise la méthode getType() 
    Le paramètre FullName permet d’afficher le type complet de la variable. 
    Lorsque l’on souhaite déclarer une variable de type String qui va contenir une chaîne de 
caractères, il faut encadrer les caractères avec des doubles quotes. 
    La variable $b est de type SystemString car la valeur 1 est encadrée avec des doubles quotes.

    Initiation à PowerShell

    Les variables vont contenir également des objets, qui par la suite vont être réutilisés dans d’autres
    traitements.

    Pour contenir des objets dans une variable, on déclare la variable puis on assigne un résultat de
    commande à cette variable. 

    On obtient une variable de type System.Object qui contient le résultat de la commande Get-
Aduser.

    Lorsque la variable est déclarée, elle est utilisable dans la console. 

    Pour visualiser son contenu, il suffit de saisir son nom précédé du $. 
    La variable peut également servir de conteneur à une saisie dans la console. Elle va être combinée 
à la commande Read-Host 
    La variable peut être utilisable avec la commande Write-Host pour afficher le contenu dans une 
chaîne de caractères avec des outils de mise en forme. 
    La valeur de la variable $choix est affichée dans la chaîne de caractères. 
    Les variables de type System.Object peuvent être utilisées pour afficher une ou plusieurs propriétés 
d’un ou des objets qu’elles contiennent.

    On utilise le . à la suite de la variable pour indiquer le nom de la propriété à afficher.

    Les types de variables

    Démonstration 02 du module 4

    L’objectif de cette démonstration est de découvrir comment nous pouvons lier les variables entre
    elles, en gardant à l’esprit que les variables doivent être de type identique.

    Déroulement

    •
    Dans le cas où nous disposons de deux variables de même type, la variable contenant le résultat
    sera du même type que les variables d’origine. 

    • 
Voici ce qu’il est possible de faire avec des variables de type String 
    Les variables de type String peuvent être fusionnées pour obtenir une chaîne de caractères.

    On récupère les valeurs des propriétés avec le « . » puis on le stocke en variable. 

    La variable finale conserve le type SystemString et hérite des variables $e et $f. 
    Le type de variable int va interpréter les chiffres et va permettre d’utiliser les opérateurs 
mathématiques.

    Initiation à PowerShell

    Les structures : If, Else, ElseIf

    Démonstration 04 du module 4

    L’objectif de cette démonstration est de montrer comment les variables permettent de
    manipuler des objets, des valeurs de propriétés à l’aide de conditions appliquées à ces variables
    pour déclencher ou non d’autres commandes ou méthodes.

    Déroulement 

    • 
La structure If est essentielle, car elle conditionne l’exécution d’une commande en fonction 
de la réponse à un test.

    •
    Le résultat du test peut être soit « Vrai » soit « Faux », mais aucune autre valeur. 

    • 
Le test est effectué entre les parenthèses. Dans notre exemple on teste la valeur de la variable 
$x.

    Si la valeur est supérieure à 0 alors le test répond « Vrai ». Dans ce cas, la commande entre les
    accolades est exécutée. 

    Dans cet exemple $x n’est pas supérieur à 0, donc le test répond « Faux » : aucune commande ne 
sera exécutée. 
    Si l’on souhaite exécuter une commande lorsque le test est « Faux », alors il faut ajouter le paramètre

    Repères¶

    • Objectif : utiliser des variables PowerShell et intégrer des structures de commandes dans des scripts de base.
    • Organisation : un seul TP composé de cinq exercices.

    2. Devinette avec condition et boucle post-test.
    3. Collections d’utilisateurs avec condition et Foreach.
    4. Menu avec While, If ou Switch.
