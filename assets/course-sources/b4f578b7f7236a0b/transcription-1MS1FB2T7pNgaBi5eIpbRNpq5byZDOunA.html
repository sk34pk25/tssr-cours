Le service DHCP

TP du Module 05 – Le service DHCP

Avant de démarrer ce TP, il convient d’avoir suivi les vidéos du module 5.

Durée estimée

1 à 2 heures

Énoncé

Prérequis :

•
Avoir réalisé le TP précédent du Module 04.

Création des machines virtuelles :

•
Une machine virtuelle cliente Windows 10 sur le réseau VmNet10.
•
Une machine virtuelle serveur Windows 2019 Standard sur le réseau VmNet10.

Installation du service DHCP

•
Définir un nouveau plan d’adressage pour votre réseau VmNet10 avec : 

o Une plage de 100 adresses pour les postes clients. 
o Les adresses statiques pour les serveurs. 
 
• 
Configurer le service DHCP sur le nouveau serveur Windows 2019 Standard pour : 
o Fournir des adresses IP sur les postes clients. 
o Fournir l’ensemble des paramètres IP nécessaires aux postes clients. 
o Ne pas fournir les adresses IP prévues pour les serveurs (configuration

statique).
