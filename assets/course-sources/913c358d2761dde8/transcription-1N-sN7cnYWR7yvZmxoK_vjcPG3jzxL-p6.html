La configuration du service
DNS

Démonstration 01 du module 06

Cette démonstration décrit les différentes étapes relatives à l’installation du service DNS sur une
machine virtuelle Windows.

Déroulement

•
Prérequis

Avoir installé et configuré une VM Windows Server.

•
Accès à la console d’installation.

Lors de l’accès à la session du serveur, le Gestionnaire de Serveur ou Serveur Manager se lance
automatiquement.

Pour lancer la console permettant l’ajout d’un rôle, cliquer sur Manage ou Gérer (1) puis sur Add
Roles and Features ou Ajout de Rôles et Fonctionnalités (2).

•
Choix du rôle à installer.

Cliquer sur le bouton Suivant (1), puis encore une fois sur le bouton Suivant (2). Sur l’écran,
Sélectionner le serveur de destination, cliquer sur le bouton Suivant (3). Sur l’écran Sélectionner des
rôles de serveurs, cocher la case Serveur DNS (4). Sur la fenêtre contextuelle qui vient d’apparaître,
cliquer sur le bouton Ajouter des fonctionnalités (5), puis sur le bouton Suivant (7). Sur l’écran
Sélectionner des fonctionnalités, cliquer sur le bouton Suivant (8). Sur l’écran Serveur DNS, cliquer
sur le bouton Suivant (9). Continuer jusqu’à la finalisation du rôle.

Présentation de la console

Cliquer sur le raccourci précédemment créé afin d’ouvrir la console DNS.

Zone de recherche directe (1) : processus de recherche d'une adresse IP basée sur le nom d'hôte
dans DNS.

Zone de recherche inversée (2) : processus de recherche de nom d’hôte basé sur l’adresse IP dans
le système DNS.

Redirecteurs conditionnels (3) : le serveur DNS peut être configuré pour faire appel à
des redirecteurs ciblés pour des espaces de noms identifiés. Résoudre des espaces de noms privés
non référencés et non résolvables dans l’arborescence d’espaces de noms publics. D’optimiser la
résolution d’espaces de noms qui sont souvent sollicités.

DNS (4) et Redirecteurs (5) : si le serveur est configuré de telle sorte à utiliser la redirection, il
demandera à son serveur redirecteur de trouver les réponses aux requêtes de ses clients.
