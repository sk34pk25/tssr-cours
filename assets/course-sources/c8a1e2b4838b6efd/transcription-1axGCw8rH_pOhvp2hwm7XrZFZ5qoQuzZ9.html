Le routeur

TP du Module 04 – Le routage

Avant de démarrer ce TP, il convient d’avoir suivi les vidéos du module 4.

Durée estimée

30 minutes à 1 heure

Solution

Prérequis :

•
Déployer la machine Virtuelle CLI-01-TP8-OK.

•
Identifiant : Admineni - Mot de passe : Pa$$w0rd

•
Déployer la machine virtuelle RTR-01-TP8-OK sur VMware Workstation.

•
Identifiant : admin - Mot de passe : Pa$$w0rd

Création des VM

•
Une VM Windows 10 nommée CLI-00 qui fera office de poste client.
•
Une VM routeur pfSense nommée RTR-00.


Connectivité

•
Configurer le poste client CLI-00. 

o Carte réseau : VMnet 10 
o Adresse IP : 192.168.0.10/24.

•
Configurer le routeur RTR-00. 

o 1ère carte réseau : Bridge. 
o Adresse IP : utiliser l’adressage dynamique. 
o 2ème carte réseau : Bridge. 
o Utiliser l’adresse IP 172.16.0.1/16 
o 3ème carte réseau : VMNET10

Routes

•
Indiquer ci-dessous les opérations que vous avez réalisées sur votre routeur PfSense :

1. Mise en place d’une adresse IP fixe sur l’interface WAN du PfSense (la même
adresse que celle obtenue via le DHCP).
2. Mise en place d’une adresse IP fixe sur l’interface LAN.
3. Connexion sur l’interface web PfSense depuis le client Windows 10 (NB : par défaut
le login est admin et le mot de passe Pa$$w0rd).
4. Désactivation du « Block private networks and loopback adresses » pour les
interfaces WAN et LAN :

5. Suppression des règles superflues :

6. Suppression et création de la gateway adéquate (par où vous souhaitez passer
pour atteindre le réseau cible).
