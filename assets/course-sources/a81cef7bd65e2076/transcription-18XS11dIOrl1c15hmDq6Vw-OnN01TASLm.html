L’imbrication

Démonstration 09 du module 4

Les structures sont faites pour être imbriquées les unes avec les autres afin de répondre à un
besoin. L’objectif de cette démonstration est de vous donner un exemple.

Déroulement

•
Nous allons combiner plusieurs structures afin de créer un menu interactif.

•
Ce menu doit être intégré dans une boucle qui s’arrêtera lorsque l’utilisateur appuiera sur une
touche assignée à la sortie du menu.

•
La variable « choix » est réinitialisée à chaque tour de boucle. Cela permet de ne pas garder
en mémoire la valeur du choix précédent.
