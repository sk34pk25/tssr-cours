Les liens

TP du Module 05 – Utiliser des fichiers sous Linux

Avant de démarrer ce TP, il convient d’avoir suivi les vidéos du module 5 et d’avoir
effectué le TP précédent.

Durée estimée

45 à 60 minutes

Énoncé

Dans le module que vous venez de parcourir, vous trouverez les commandes nécessaires
pour répondre aux questions.

1. Créez un lien physique du fichier Edition vers le fichier edition1.txt. Vérifiez que vous
pouvez afficher son contenu.

2. Créez un lien symbolique du fichier
edition1.txt
vers le fichier
/tmp/stagxx/edition2.txt, vérifiez que vous pouvez afficher son contenu.
