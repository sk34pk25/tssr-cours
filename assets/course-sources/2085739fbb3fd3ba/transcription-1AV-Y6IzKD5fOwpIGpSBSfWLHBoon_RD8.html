Services réseau en environnement Microsoft

Disponibilité du service
DHCP

TP du Module 05 – Le service DHCP

Avant de démarrer ce TP, il convient d’avoir suivi les vidéos du module 5 et terminé le TP
précédent.

Durée estimée

1 à 2 heures

Énoncé

Prérequis :

•
Avoir réalisé le TP précédent du Module 05.

Définition des paramètres :

•
Définir le plan d’adressage et les paramètres pour : 

o Fournir à vos postes clients des adresses IP dans votre réseau VmNet10. 
o Fournir aux postes client du réseau 192.168.1.0/24 des adresses IP de votre

serveur en cas de défaillance du serveur.
Vous configurerez les serveurs avec la fonction de FailOver.

Configuration pour les clients du 1er réseau :

•
Configurer les plages adaptées sur les deux serveurs DHCP.
•
Configurer le relais DHCP sur le routeur adapté.
•
Tester le bon fonctionnement. 

o Si le serveur DHCP du 1er réseau est arrêté. 
o Si le serveur DHCP du 1er réseau est relancé. 
o Vérifier la connectivité avec le réseau VmNet10 du VmNet11. 
 
Configuration pour les clients du 2e réseau :

•
Configurer les plages adaptées sur les deux serveurs DHCP.
•
Configurer le relais DHCP sur le routeur adapté.
•
Tester le bon fonctionnement. 

o Si le serveur DHCP du 2e réseau est arrêté. 
o Si le serveur DHCP du 2e réseau est relancé. 
o Vérifier la connectivité avec le réseau VmNet11 du VmNet10.
