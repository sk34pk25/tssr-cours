Export-Object
Démonstration 10 du module 3


 L’objectif de cette démonstration est de présenter la commande Export-Object

Déroulement

Une fois la mise en forme terminée,  il faut exporter les résultats de commandes vers un logiciel ou
une application. Selon le format choisi, il va falloir exporter ces données vers un fichier.
•     Il existe différents types de fichiers dont le format est pris en charge nativement par la console
   PowerShell :
              o  Le format CSV qui comporte un délimiteur. La plupart du temps, ce délimiteur
                     est le point-virgule.
              o  Certains  logiciels peuvent demander  la présence d’un autre délimiteur
             comme la virgule.

On peut constater que la première ligne du fichier CSV contient le TypeName de l’objet.

Afin de ne  pas  avoir  le  type  d’objet  dans  le  fichier CSV on  ajoute  le  paramètre
NoTypeInformation.





Si on exécute une commande d’export sur un fichier existant, la commande va automatiquement
supprimer les données présentes dans le fichier.

Pour éviter l’écrasement des données, on ajoute le paramètre Append.

 On se retrouve avec les comptes d’utilisateur à nouveau à la suite de la première exportation.
Le second format pris en charge nativement est le CliXml.  Il permet l’export de données vers des
applications web.
Les règles d’exportation sont identiques au CSV ; on élimine le délimiteur inutile dans le format CSV.





D’autres formats peuvent être ajoutés par l’intermédiaire de l’installation de module.
Il est intéressant de pouvoir exporter des données sous forme de fichiers de base de données, de
code PHP ou de fichier XLSX.
