2.1.3  Vous adopterez une convention de nommage pour les groupes, que vous
      conserverez, quel que soit le système d’exploitation.

Nous pouvons proposer comme convention de nommage :

L_ Le nom du groupe_Le droit accorder au groupe

L indiquant que le groupe est local
R indiquant le droit de lecture
W indiquant le droit de modification
X indiquant le droit d’exécution
CT indiquant le droit de contrôle total

Exemple :
L_Comptabilité le groupe contenant tous les comptables
L_Commercial_W le groupe pour les commerciaux avec les droits en modification
L_Informatique_CT les groupes pour les informaticiens avec le droit en contrôle total

7.2.2  Sur le poste Debian : Plusieurs applications installées depuis les sources vont
       être installées dans /opt. Pour plus de flexibilité, l’espace disque accessible
     à cet emplacement sera géré au moyen de LVM.

        7.2.2.1 Vous ajouterez 2 nouveaux disques SCSI de 20Go ; vérifier leur
           bonne prise en compte par le système.

        7.2.2.2 Au moyen des commandes appropriées, vous créerez un volume
              logique LMV de 32Go

        7.2.2.3  Le volume logique créé précédemment est à formater en ext4. Il
               doit être accessible depuis /opt et ce de façon permanente.

Pour cela, nous devons utiliser la méthode LVM pour créer un volume logique
s'étendant sur les deux disques physiques.

Une fois les disques ajouter à la VM nous la redémarrerons.

Nous aurons besoin dans un premier temps de trouver le gestionnaire lvm :


#apt search lvm

Installons-le :


#apt install lvm2

Nous allons d'abord préparer nos deux disques durs à recevoir des volumes
logiques. Nous allons donc créer un volume physique pour les deux disques durs,
nous pourrons voir le résultat grâce à la commande pvdisplay :


# pvcreate /dev/sdc /dev/sdd





# pvdisplay
Page 141
Nous pouvons maintenant créer un groupe de volume englobant les deux disques
dur, ils seront alors ensemble considérés comme un seul disque dur logique (nous
l'appellerons applications):


# vgcreate applications /dev/sdc /dev/sdd

 Enfin, nous pouvons créer un volume logique nommé opt, d'une taille de 32Go
 dans le groupe de volumes applications :


# lvcreate -n opt -L 32G applications
# lvdisplay

MSP systèmes clients

Nous pouvons maintenant formater ce nouveau volume en ext4 :


# mkfs.ext4 /dev/applications/opt





Enfin nous pouvons le monter de manière permanente dans le dossier /opt en ajoutant
une ligne au fichier /etc/fstab puis en relançant le montage des disques :


# echo "/dev/mapper/applications-opt /opt ext4 defaults 0 0" >> /etc/fstab
# mount -a

        7.2.3.2  La colonne à l’aide d’une formule “Moyenne par élève”
=MOYENNE(B5:E5)

        7.2.3.3  La ligne “Total par matière” est une somme des notes des employés dans
            une matière
=SOMME(B5:B12)

        7.2.3.4  La ligne “Moyenne par matière” est une moyenne des notes des employés
            dans une matière

=MOYENNE(B5:B12)

        7.2.3.5  La ligne “note maximum” indique la meilleure note des employés dans une
             matière

=MAX(B5:B12)

        7.2.3.6  La ligne “note minimum” indique la note la plus faible des employés dans
            un matière

=MIN(B5:B12)

        7.2.3.7  La ligne “nombre d’élèves” indique le nombre d’élèves
=NBVAL(A5:A12)
