fonctionne correctement.

utilisé par le système, nous devons dans un premier temps redémarrer en mode
maintenance :

# init 1

Une fois en mode maintenance, nous pouvons copier le contenu de "/var/log" dans
un dossier temporaire, en conservant les permissions :

# mkdir /tmp/logs
# cp -rp /var/log /tmp/logs

Nous pouvons alors modifier le fichier "/etc/fstab" puis vérifier que le montage se
déroule correctement :

# echo "LABEL=LOGS /var/log xfs defaults 0 0" >> /etc/fstab
# mount -a

Nous pouvons maintenant recopier les données de log dans la nouvelle partition :

# cp -rp /tmp/logs/* /var/log/

Jettons un œil dans le contenu de /var/log et dans tmp/logs :

#ls -al /var /log
#ls -al /tmp/logs

Maintenant redémarrons la machine :

# reboot

Nous pouvons vérifier que de nouvelles données ont étés inscrites dans les journaux

# tail /var/log/syslog
