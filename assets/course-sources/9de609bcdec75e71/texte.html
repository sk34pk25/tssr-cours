                                                        Administration Debian GNU/Linux
Gestion de la journalisation
TP du Module 12 – Maintenance d’un système en production


 Avant de démarrer ce TP, il convient d’avoir suivi les vidéos des modules 1 à 12 et d’avoir
 réalisé les TP proposés.


           Durée estimée

           30 à 45 minutes

Énoncé

  I.  Recherche d’informations : sur le serveur sans
    environnement graphique

    •  Trouver dans les journaux les différentes ouvertures de sessions

        o   Les reporter dans un fichier /adm/sessions.txt


    •  Rechercher dans les journaux des informations sur le disque sda, (dont le nombre
     de secteurs et la taille du disque)

  II.  Configuration de rsyslog

    •  Activer la journalisation pour le service cron

    •  Stocker les informations relatives au démon cron dans le fichier /adm/logs/cron.log

    •   Définir  comme   fichier  contenant   tous   les  évènements  d'avertissement
      /adm/logs/warnings.log

 III.  Générer des messages de type avertissement

    •  A l’aide de logger, créer des messages de niveau avertissement.

    •   Vérifier le bon fonctionnement des étapes précédentes.

Solution

Une solution est proposée pour ce TP sous la forme d'un PDF commenté, disponible dans les
ressources à télécharger.
