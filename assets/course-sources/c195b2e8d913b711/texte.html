                                                               Utilisation d'une distribution GNU/Linux
Utilisation des systèmes
TP du Module 08 – Mécanismes avancés de Linux et Bash


 Avant de démarrer ce TP,  il convient d’avoir suivi les vidéos du module 8 et d’avoir
 effectué le TP précédent.


           Durée estimée

           45 à 60 minutes

Énoncé

   Dans  le module que vous venez de  parcourir, vous trouverez  les commandes
   nécessaires pour répondre aux questions.

    1.  Listez tous  les processus qui  finissent par un  d. Le  résultat sera stocké dans
      $HOME/process/daemons.txt.





    2. Recherchez les fichiers dont le nom se termine par .conf à partir de la racine. Cette
      recherche ne devra être effectuée que sur le système de fichier racine. Le résultat
      sera   affiché  à   l'écran    tout   en   étant   stocké   dans    le    fichier
       $HOME/resultats/fichiers.conf.

     nombre de fichiers trouvés au point 2, sans utiliser le fichier fichiers.conf. Le résultat
