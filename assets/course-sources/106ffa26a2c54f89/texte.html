1. Introduction aux Systèmes d'Exploitation (OS)

Un système d'exploitation (Operating System - OS) est un ensemble de programmes qui gère
les ressources matérielles d'un ordinateur et fournit aux applications des services pour
fonctionner.

Composants principaux d'un OS

  ●​ Noyau (Kernel) : Cœur du système gérant le processeur (CPU), la mémoire vive (RAM)
       et la communication matérielle.
  ●​  Interpréteur de commandes (Shell / CLI) : Interface en ligne de commande permettant
     à l'utilisateur ou aux scripts de donner des instructions.
  ●​  Interface Graphique (GUI) : Environnement visuel facilitant l'interaction utilisateur.
  ●​ Système de Fichiers (File System) : Organisation et structuration des données sur le
      stockage.

2. Évolution, Modèle WaaS et Éditions de Windows 10

Windows as a Service (WaaS)

Microsoft met à jour Windows 10 de manière continue à travers le modèle WaaS :
  ●​ Feature Updates : Mises à jour majeures de fonctionnalités diffusées deux fois par an
      (Canal semi-annuel).
  ●​  Quality Updates : Patchs de sécurité et correctifs distribués mensuellement (Patch
      Tuesday).
  ●​ Windows Insider : Programme de bêta-test pour essayer les builds en avant-première.

3. Modèle OSI et Communication Réseau

Le modèle OSI (Open Systems Interconnection) comporte 7 couches théoriques définissant les
étapes de la communication réseau :

        N°         Couche               Unité de données      Protocoles /
                                       (PDU)               Équipements
