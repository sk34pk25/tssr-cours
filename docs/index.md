## Une méthode de travail durable

1. Suivre le [parcours chronologique](parcours/index.md) dans l’ordre réel des semaines de formation.
2. Lire le cours et noter le résultat attendu avant toute modification.
3. Réaliser le TP sans ouvrir immédiatement sa correction.
4. Vérifier avec une commande, un journal ou un test fonctionnel.
5. Consolider avec les fiches de révision, mémos et pages de dépannage.

!!! warning "Supports historiques"
    Certains supports ciblent Windows 10, Debian 11/12, GLPI 9.5, PHP 7.4, FusionInventory et des interfaces Microsoft 365 anciennes. Les pages concernées distinguent la méthode pédagogique historique des recommandations actuelles vérifiées sur les sites officiels.
