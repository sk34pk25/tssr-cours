# Révision — Module 05 — Le service DHCP

## Contrôler le bail DHCP

DORA pour la première attribution, puis renouvellement. Étendue, exclusion, réservation et options structurent les baux. Le relais franchit la limite de diffusion.

## Exercice de rappel

Quelles options fournissent la passerelle, les DNS et le suffixe du scénario ?

    3, 6 et 15. L’option 12 porte le nom d’hôte.
