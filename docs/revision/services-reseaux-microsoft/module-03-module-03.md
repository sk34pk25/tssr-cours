# Révision — Module 03 — Stratégies de groupe

## Calculer la stratégie effective

Local, Site, Domaine et UO. Lier la GPO au conteneur de l’objet ciblé, puis vérifier ordre, filtres et exceptions d’héritage.

## Exercice de rappel

Le lien parent est forcé. Une UO bloque l’héritage. Le lien parent peut-il encore s’appliquer ?

??? success "Réponse"
    Oui. Le lien forcé traverse le blocage de l’héritage.

## Vérifier en laboratoire

Pour chaque réglage, relever son type ordinateur ou utilisateur, la GPO et son lien, le compte de test et le résultat. Prévoir un compte exclu pour chaque ciblage.
