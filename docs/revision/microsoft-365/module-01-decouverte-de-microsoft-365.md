# Fiche de révision — Module 01 — Découverte de Microsoft 365

## Les notions essentielles

- **SaaS** : un logiciel ou service hébergé sur des serveurs distants, consommé en ligne dans le cadre d'un abonnement.
- **Plan** : une offre organisée selon un type d'organisation ou d'usage.
- **Licence** : le droit attribué à un utilisateur pour accéder aux services prévus par l'offre.
- **Tenant Microsoft 365** : l'ensemble des services de l'abonnement associé au domaine de l'organisation.
- **Administrateur global** : l'utilisateur présenté par le support comme ayant les privilèges les plus élevés sur le tenant.

## Les services à savoir situer

| Service | À retenir |
|---|---|
| Exchange Online | Messagerie et boîte aux lettres. |
| Microsoft Teams | Collaboration et échanges d'équipe. |
| SharePoint Online | Organisation et partage de l'information, des utilisateurs et des projets. |
| OneDrive | Fichiers associés à l'utilisateur. |
| Office 365 ProPlus | Applications Office citées dans le support. |
| Azure AD | Service d'identité cité parmi les éléments de base. |

## Créer un tenant : ordre de préparation

1. Sélectionner le plan adapté.
2. Préparer une adresse électronique valide.
3. Renseigner les données de l'entreprise.
4. Choisir le nom de tenant.
5. Vérifier les informations puis valider l'inscription.

## Vérifications importantes

- Le besoin de l'utilisateur est-il associé au bon service ?
- Le plan et la licence envisagés correspondent-ils à ce besoin ?
- L'administrateur global est-il identifié ?
- Le nom de tenant a-t-il été contrôlé avant validation ? Le support le présente comme non modifiable.
- Un domaine personnalisé est-il nécessaire pour utiliser des adresses de l'organisation ?

## Chiffres et contrôles du support

- 75 millions d’utilisateurs actifs par jour fin mai 2020, et 4 datacenters en France.
- Concurrents affichés : Zoho, G Suite, HyperOffice, Amazon Web Services, IBM Cloud.
- Le nom de tenant, par exemple `admin@monentreprise.onmicrosoft.com`, n’est pas modifiable.
- Une adresse `@votreentreprise.fr` suppose un domaine loué, puis un domaine personnalisé dans Microsoft 365.
