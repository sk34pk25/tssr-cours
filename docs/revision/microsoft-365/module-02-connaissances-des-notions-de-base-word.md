# Fiche de révision — Module 02 — Connaissances des notions de base Word

## Les repères de l'interface

- La **barre de titre** affiche le fichier et le logiciel.
- Le **ruban** regroupe les commandes par onglet.
- La **barre d'accès rapide** est personnalisable.
- La **zone de rédaction** contient le texte.
- Les **barres de défilement** servent à parcourir le document.
- La **barre d'état** fournit des informations sur le document.
- La **règle** sert notamment à placer les taquets de tabulation ; elle n'est pas affichée par défaut.

## La méthode de production

1. Afficher les caractères non imprimables.
2. Rédiger le contenu sans le mettre en forme au fil de la frappe.
3. Identifier les titres, paragraphes et listes.
4. Créer ou appliquer les styles nécessaires.
5. Configurer la liste à plusieurs niveaux et ses retraits.
6. Utiliser les sauts de page, puis générer le sommaire une fois les titres structurés.
7. Vérifier l'ensemble du document avant la finalisation.

## Styles, titres et paragraphes

Un style peut réunir la police, la taille, l'alignement, les retraits, les espacements et le comportement du paragraphe suivant. Dans le support, les titres sont liés à une hiérarchie et à une liste à plusieurs niveaux : une apparence identique sans style ne suffit pas.

Pour un paragraphe, contrôlez l'alignement, les tabulations, les retraits et les espacements. Le support demande d'éviter les paragraphes vides pour créer de l'espace.

## Le TP Word : ce qu'il faut savoir faire

Le TP part d'un document brut et demande de le structurer avec des styles de titres, de paragraphes et de listes. Il prévoit notamment une table des matières, un filigrane, un en-tête, une numérotation de pages et une page de garde. La correction propose d'abord de recenser les styles nécessaires, puis de les préparer avant de les appliquer au document entier.

## Vérifications avant remise

- [ ] Les caractères non imprimables ont été contrôlés.
- [ ] Chaque titre utilise le style prévu.
- [ ] La liste à plusieurs niveaux suit la hiérarchie des titres.
- [ ] Les retraits, tabulations et espacements sont cohérents.
- [ ] Les sauts de page sont utilisés au bon endroit.
- [ ] Le sommaire reflète les titres structurés.
- [ ] Le résultat est comparé aux attendus du TP sans recopier la correction mécaniquement.
