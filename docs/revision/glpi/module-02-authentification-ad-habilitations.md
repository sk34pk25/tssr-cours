## Méthode express

1. Identifier le besoin ou le symptôme.
2. Relever l’état actuel sans le modifier.

4. Mesurer le résultat.
5. Documenter et, si nécessaire, revenir en arrière.

- Valider uniquement à l’écran sans test fonctionnel.
