# Révision — M04 : Fichiers, dossiers et métacaractères

## Gestes à retenir

| Besoin | Repère |
|---|---|
| Répertoire courant | pwd |
| Noms présents, y compris cachés | ls -A |
| Créer un nouveau fichier | touch MonPremierFichier |
| Attributs du fichier | ls -l MonPremierFichier |
| Noms terminés en .conf | ls /etc/*.conf |
| Attributs du répertoire | ls -ld /tmp |

## Se contrôler

- Quelle commande identifie le répertoire courant ? **pwd.**
- Pourquoi ls -ld /tmp respecte-t-il la consigne ? **-d demande les attributs du répertoire lui-même.**
- Que fait le motif /etc/*.conf ? **Le shell sélectionne les noms terminés par .conf directement dans /etc.**

## Pièges du support

- Les permissions, propriétaires et dates de la capture illustrent le serveur source : relever ceux du laboratoire courant.
- Le titre du module inclut les métacaractères, mais son TP propre concerne fichiers et dossiers ; le second TP est rattaché au module06 d’après le titre écrit dans son document.
