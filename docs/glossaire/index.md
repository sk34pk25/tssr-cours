# Glossaire

**ACL**
:   Liste de contrôle d’accès décrivant les autorisations associées à une ressource.

**ARP**
:   Protocole de résolution d’une adresse IPv4 en adresse de liaison sur le réseau local.

**CIDR**
:   Notation par longueur de préfixe utilisée pour décrire la partie réseau d’une adresse IP.

**CMDB**
:   Base de données des éléments de configuration et de leurs relations.

**DHCP**
:   Service attribuant automatiquement des paramètres réseau.

**DNS**
:   Système de résolution des noms en données, notamment des adresses IP.

**GLPI**
:   Solution libre de gestion de parc et de services informatiques.

**GPO/LGPO**
:   Stratégie de groupe de domaine ou stratégie de groupe local.

**IPv4**
:   Version d’IP utilisant des adresses sur 32 bits.

**IPv6**
:   Version d’IP utilisant des adresses sur 128 bits.

**ITIL**
:   Ensemble de bonnes pratiques de gestion des services informatiques.

**LVM**
:   Couche de gestion de volumes logiques entre disques et systèmes de fichiers.

**PDU**
:   Unité de données manipulée à une couche de protocole.

**SLA**
:   Accord décrivant des objectifs de niveau de service mesurables.

**SMB**
:   Protocole utilisé notamment pour les partages de fichiers Windows.

**UAC**
:   Mécanisme Windows d’élévation contrôlée des privilèges.

**WIM**
:   Format d’image Windows utilisé pour la capture et le déploiement.
