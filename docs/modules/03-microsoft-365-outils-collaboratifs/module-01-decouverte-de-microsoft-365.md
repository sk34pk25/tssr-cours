#### Qu’est-ce qu’une offre SaaS ?

!!! note "À retenir"
    **SaaS** Software as a Service Le Software as a Service ou logiciel en tant que service, est un modèle d'exploitation commerciale des logiciels dans lequel ceux-ci sont installés sur des serveurs distants plutôt que sur la machine de l'utilisateur.

**SaaS** Software as a Service

Le Software as a Service ou logiciel en tant que service, est un modèle d'exploitation commerciale des logiciels dans lequel ceux-ci sont installés sur des serveurs distants plutôt que sur la machine de l'utilisateur. Les clients ne paient pas de licence d'utilisation pour une version, mais utilisent librement le service en ligne ou, plus généralement, payent un abonnement.

(Wikipédia)

### Page 8

#### Créer un Tenant Microsoft 365

!!! note "À retenir"
    Sélectionnez un plan Exemple : famille, A1, E5, F3 Fournissez une adresse mail valide Exemple : prénom.nomannée@exemple.lab Entrez les données de votre entreprise Exemple : nom et nombre de salariés Choisissez le nom de votre Tenant Exemple : admin@monentreprise.onmicrosoft.com Validez Terminez l’inscription

1. Sélectionnez un plan
   Exemple : famille, A1, E5, F3
2. Fournissez une adresse mail valide
   Exemple : prénom.nomannée@exemple.lab
3. Entrez les données de votre entreprise
   Exemple : nom et nombre de salariés
4. Choisissez le nom de votre Tenant
   Exemple : admin@monentreprise.onmicrosoft.com
5. Validez
   Terminez l’inscription

#### Votre Tenant

- Nom de Tenant type :
  - nomdeladministrateurglobal@dom.onmicrosoft.com
- Possibilité d’envoyer ou de recevoir des courriels pour ce domaine
- Le Tenant n'est pas modifiable
- Afin d’avoir une adresse mail en @votreentreprise.fr :
  - Location d’un domaine internet puis création d’un domaine personnalisé dans Microsoft 365
