Le réseau global

TP du Module 04 – Le routage

Avant de démarrer ce TP, il convient d’avoir suivi les vidéos du module 4 et réalisé le TP
précédent.

Durée estimée

1 à 2 heures

Énoncé

Prérequis :

•
Avoir réalisé le TP précédent du Module 04.

Création des VM

•
Deux VM Windows 10 nommées CLI-00 et CLI-01 qui feront office de postes clients.
•
Trois VM routeur pfSense nommée RTR-00, RTR-01, RTR-02.

Connectivité :

•
Configurer le poste client CLI-00. 

o Carte réseau : BRIDGE 
o Adresse IP : Utiliser la deuxième IP disponible du réseau.



•
Configurer le poste client CLI-01. 

o Carte réseau : BRIDGE 
o Adresse IP : utiliser la deuxième IP disponible du réseau.
