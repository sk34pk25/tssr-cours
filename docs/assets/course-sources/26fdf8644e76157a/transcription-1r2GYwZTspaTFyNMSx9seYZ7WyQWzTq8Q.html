Administration Debian GNU/Linux


Les options de useradd : -m pour forcer la création du répertoire personnel de l'utilisateur
-s pour préciser le binaire du shell à utiliser, -g pour le groupe principal, -G pour les groupes secondaires
Id permet de vérifier les groups de l’utilisateur. Ne pas oublier de modifier le mot de passe avec passwd

•

o Répertoire personnel  
/home/frederic 
o Mot de passe  
AchAngEr

Ce mot de passe sera à changer à la première
ouverture de session 

o Groupes secondaires  
stagiaires, documentation


On ajoute l’option -d pour préciser le dossier /home/fred


La saisie du mot de passe ne change pas


Le man passwd contient cette information concernant l’expiration du mot de passe d’un utilisateur


Après la saisie de la commande pour forcer l’expiration du mot de passe, l’on peut vérifier la bonne prise en

compte en changeant d’utilisateur. Il suffit d’annuler avec ^C pour ne pas aller au bout de la procédure.
