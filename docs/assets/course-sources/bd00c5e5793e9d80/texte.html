                                                         Systèmes Clients Microsoft
Les LGPO
TP du Module – Les stratégies de groupe local

 À travers ce TP vous allez découvrir par vous-mêmes les consoles d'édition de stratégie
 de groupe local et de stratégie de sécurité.
 Vous les utiliserez pour modifier les stratégies par défaut dans le but de personnaliser les
 environnements de travail de votre VM et vous augmenterez la sécurité du système.
 Vous testerez vos LGPO pour vous assurer qu'elles soient fonctionnelles.

       Durée estimée

          1 heure

Énoncé

Lisez l'ensemble de ce TP avant de vous lancer dans la pratique


       Sur Win10-XX, à l'aide des consoles appropriées appliquez les consignes suivantes :
        o  Pour augmenter le niveau de sécurité d'accès aux ressources de votre VM,
             tous les utilisateurs devront utiliser un mot de passe avec les caractéristiques
             suivantes
            o  Longueur minimale : 7 caractères
            o  3 mots de passe seront conservés dans l'historique
            o     Il devra respecter les exigences de complexité
