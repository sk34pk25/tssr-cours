  Manipulation des objets
 Introduction

            • Comme abordé précédemment, le résultat d’exécution de commandes peut
           être composé d’un ensemble objets.
         PS > Get-Service
            • Le nombre d’objets étant souvent élevé, il est important de pouvoir
           sélectionner et mettre en forme le résultat d’une commande.

         PS > Get-EventLog
            • L’utilisation de redirections au moyen de pipeline (caractère | ) permet
            d’effectuer des commandes de triage, de mise en forme, de sélection et
         également de conditionner le résultat final.

  Manipulation des objets
 Le pipe

            • Le pipe | permet de passer un ou plusieurs objets à la commande qui suit.
          PS > Get-Service | Get-Member
            • Le pipe | peut être utilisé à plusieurs reprises, tant que l’on dispose d’objets à
              traiter.

          PS > Get-EventLog –LogName « System » | Select-Object Name | Format-Table
            • Le pipe | utilise une variable réservée qui est $PSItem. Cela permet de cibler
         une propriété d’un objet.

        PS > Get-Process | Select Name,Id | Where { $PSItem.Id –gt 1500 –and $PSItem.Id –lt 2000}

  Manipulation des objets
 La commande Select-Object

        La commande Select-Object permet de sélectionner une ou plusieurs
         propriétés.
            • À l’exécution de la commande, seules les propriétés sélectionnées seront affichées ou
             utilisables dans une troisième commande.
        PS > Get-Service | Select-Object –Property Name
            •  Ici, seule la propriété Name de tous les services sera affichée.
        PS > Get-Service | Select-Object –Property  Name,Status

            • Pour sélectionner plusieurs propriétés, on utilise la , .
        PS > Get-Service | Select   Name,Status
            • La commande Select-Object peut se réduire.

  Manipulation des objets
 La commande Select-Object

         La commande Select-Object permet de sélectionner des objets en fonction
       de l’ordre dans lequel ils sont organisés.
          PS > Get-Service | Select-Object –First 5
          PS > Get-Service | Select-Object –Last 5

              • Dans le cas où plusieurs objets possèdent les mêmes valeurs pour la même propriété, il est
             possible d’obtenir un seul objet.
          PS > Get-Process | Select-Object -Unique Name
              •  Ici seuls plusieurs process partagent le même nom, Select n’affichera qu’un seul process.
              • Le paramètre ExpandProperty permet de ne pas afficher le nom de la propriété, mais
           uniquement les valeurs dans la console.
          PS > Get-Service | Select-Object –ExpandProperty Name

  Manipulation des objets
 La commande Sort-Object

         La commande Sort-Object est une commande de tri selon un critère donné.
          PS > Get-Service | Select-Object Name,Status | Sort-Object Status


             • On sélectionne d’abord les propriétés sur lesquelles on va appliquer le tri final des
             objets.
          PS > Get-Process | Select Name,id | Sort id -Descending
             •  Ici, on applique un tri par ordre décroissant sur la propriété Id.
          PS > Get-ChildItem -Path C:\Windows -File | Sort-Object -Property Length

             • La propriété Length indique le poids des fichiers en octet. Ils seront classés du
            plus faible au plus élevé.

 La commande Measure-Object


         La commande Measure-Object permet de compter le nombre d’objets,
          d’établir des moyennes, etc.
          PS > Get-Process | Measure-Object

             • L’action par défaut de Measure-Objet est le comptage.

          PS > Get-ChildItem –File | Measure-Object –Property Length -Average
             • La commande est aussi utilisable sur une propriété pour déterminer une valeur
          moyenne.

  Manipulation des objets
 La commandes Where-Object

         La commande Where-Object conditionne la présence d’un objet dans le
          résultat de sortie.
                    • Les conditions sont toujours appliquées sur des valeurs de propriété.
                    • Elles peuvent être uniques ou multiples, obligatoires ou optionnelles.

          PS > Get-Service | Where-Object -Property  Status –eq ’’Running’’
             • Dans cet exemple, ne seront affichés que les objets dont la propriété Status est
           égale à la valeur Running.
             •  Les autres ne seront pas affichés.
          PS > Get-Process | Where-Object –Property  Name –like ’’Power*’’
             • Ici la propriété nom doit débuter par Power, quelle que soit la suite. Le caractère *
          permet de ne pas tester la suite de la valeur.

  Manipulation des objets
 La commande Where-Object


           Si on applique plusieurs conditions à la commande Where-Object, on va
           utiliser les expressions logiques ET et OU.
             • Dans le cas d’un ET logique, les deux conditions doivent être valides pour que
              l’objet soit retenu.

        PS > Get-Process | Select Name,Id | Where –Filterscript{$PSitem.Id–gt1500
        –and$PSItem.Id–lt2000}

             • On peut réduire la syntaxe de $PSItem par $_.

        PS > Get-Process | Select Name,Id | Where{$_.Name–like’’Power*’’–and$_.Id
        –eq825}

  Manipulation des objets
 La commande Format-Table

            • Une fois les objets sélectionnés, conditionnés et triés, la dernière étape est
         de mettre en forme les propriétés et leurs valeurs.
            • L’objectif est d’améliorer la lecture du résultat, mais également de permettre
            l’export vers un fichier dans un ou plusieurs formats.

          PS >Get-AdUser –Filter * | SelectName,GivenName,Enabled | Format-table
            • La commande Format-Table va organiser les valeurs en colonnes.
                      • Les en-têtes de colonnes correspondent au nom de propriété.

15


  Manipulation des objets
 La commande Format-Table

            • L’ordre des colonnes est personnalisable.

           PS > Get-AdUser –Filter * | Format-table-Property Enabled,Name,SamAccountName
            •  Il est également possible de regrouper les objets par valeur de propriété
           identique.

           PS > Get-AdUser –Filter * | Format-table-GroupBy Enabled
            • Les utilisateurs seront regroupés selon l’état de leur compte actif ou inactif.


                       Le Select-Object n’est pas obligatoire pour l’utilisation des commandes de format.

  Manipulation des objets
 La commande Export-Object

           • Les valeurs contenues dans les objets sont exportables dans des formats
            utilisables dans les applications métiers. Les formats pris en charge nativement
          sont : le CSV, le CLIXML, le JSON, le HTML.

          PS > Get-AdUser –filter * | Export-CSVC:\ENI\ExportCSV.csv–Délimiter «;»





          PS > Get-AdUser –filter * | Export-CSVC:\ENI\ExportCSV.csv–Delimiter «;»
          NoTypeInformation
           • Le type d’objet ne sera plus exporté dans le fichier CSV.

  Manipulation des objets
 La commande Out-File

            • Comme en Bash, les chevrons ( > ; >> ) peuvent être utilisés pour rediriger
             le résultat de commandes dans un fichier.
            • Alternativement, la commande Out-File peut être utilisée. Elle prend en
          charge un ensemble d’options :
           PS > Get-Service | Out-File C:\ENI\Services.txt

            • Pour ajouter les données à la suite de celles présentes dans le fichier, on
           ajoute le paramètre Append.

           PS > Get-Service | Out-File C:\ENI\Services.txt –Append
           PS > Get-Service | Out-File C:\ENI\Services.txt –Width 42
            • Le paramètre Width spécifie le nombre de caractères par ligne. Par défaut le
        nombre de caractères est de 80.

  Manipulation des objets
 La commande Import-CSV

            • PowerShell prend en charge l’import de données dans les formats dans
           lesquels il permet l’export (CSV et CliXML). Cela permet leur manipulation
         dans le Shell.

             PS > Import-CSV C:\Users.csv –Delimiter « ; » | New -AdUser

            • Pendant l’importation, les paramètres du fichier CSV vont être comparés aux
           propriétés de l’objet AdUser.
