Le routeur
TP du Module 04 – Le routage


 Avant de démarrer ce TP, il convient d’avoir suivi les vidéos du module 4.


           Durée estimée

        30 minutes à 1 heure

Énoncé

Prérequis :

      Déployer la machine virtuelle CLI-01-TP8-OK.

       Identifiant : Admineni - Mot de passe : Pa$$w0rd

      Déployer la machine virtuelle RTR-01-TP8-OK sur VMware Workstation.

       Identifiant : admin - Mot de passe : Pa$$w0rd

Création des VMs.
      Une VM Windows 10 nommée CLI-00 qui fera office de poste client.
      Une VM routeur pfSense nommée RTR-00.

Connectivité :

      Configurer le poste client CLI-00.
        o  Carte réseau : VMNET10
        o  Adresse IP : 192.168.0.10/24.

      Configurer le routeur RTR-00.
        o  1ère carte réseau : Bridge.
        o  Adresse IP : utiliser l’adressage dynamique.
        o 2ème carte réseau : Bridge.
        o   Utiliser l’adresse IP 172.16.0.1/16
        o  3ème carte réseau : VMNET10
        o  Adresse IP : utiliser la dernière adresse d’hôte du réseau privé défini
           précédemment.

       Vérifier la connectivité des machines :
        o  Du poste CLI-00 vers le routeur RTR-00.
        o  Du routeur RTR-01 vers le routeur RTR-00.
        o  Du poste CLI-00 vers le poste CLI-01.
