Page 2

Des Concepts de la Virtualisation à leur mise en œuvre
Énoncé :

• Contrôler la présence de la solution de virtualisation VMware Workstation 16.

• Créer un nouveau dossier sur le volume « D » que vous nommerez « Machines virtuelles ».
Ce dossier servira de point de stockage pour toutes vos machines virtuelles créées dans
Workstation.

• Créer une VM nommée « SRV_2K19 » de type Windows Server 2019 avec pour prérequis :

          - 2 CPU / 1 cœur

          - 2 Go RAM

          - 1 carte réseau bridgée

          - 60 Go de disque en “single file”

       et activer "Virtualize Intel VT-x/EPT or AMD-V/RVI"

• Récupérer le fichier ISO de Windows Server 2019 depuis le partage"iso\os\windows\” du
serveur “distrib” et l’utiliser comme image du CDROM de la machine virtuelle.

• Procéder à l’installation de Windows Server 2019 avec « expérience utilisateur » dans la
machine virtuelle.

• Y installer les « VMware Tools ».

• Nommer la machine virtuelle puis l’arrêter.

• Faites IMPERATIVEMENT une capture instantanée “snapshot “ de la machine virtuelle
que vous nommerez « Fin Atelier 1 »
