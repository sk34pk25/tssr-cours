   1. Présentation et préparation de l'infrastructure

Le cœur de métier de la société "Support-Terre" est de proposer du support informatique
personnalisé pour les PME.

      Vous intégrez l'équipe technique du projet "TSSRC-Série-EU". Votre objectif est de
maquetter une  infrastructure en  respectant  les  contraintes imposées par  l'équipe
architecture du projet.

Prérequis

    •  Disposer d'images ISO (Windows Server, Debian, pfSense)

    •  VMware Workstation doit être installé dans votre environnement de travail

   b. Conception du plan d’adressage IPv4

D correspond au dernier octet de l'adresse IP du poste de travail fourni par l'ENI

    •  Un réseau 192.168.4xD.0 / 22 est attribué par stagiaire.

      Exemple :

       Le dernier octet de l'adresse IP du poste de travail fourni par l'ENI est
        13. 13x4=52. Le réseau qui m’est alloué est le 192.168.52.0 / 22

    •  Ce réseau  est segmenté en 4 sous réseaux, chacun ayant un masque de
       255.255.255.0 (/24)

    •  Le premier sous réseau est utilisé pour adresser le LAN Clients

    •  Le dernier sous réseau est utilisé pour adresser le LAN Serveurs

    •  Le réseau du poste de travail fourni par l'ENI est utilisé pour adresser la machine de
      l’environnement étant sur le WAN.



Reproduire le précédent schéma (ou équivalent) puis y reporter vos adresses de réseaux
locaux Clients et Serveurs.

possédera les caractéristiques suivantes :

   6. Configuration de paramètres de GPO


Pour chaque paramètre demandé, à l’issue de sa configuration, vous testerez sa bonne
effectivité sur votre poste client Windows avant de passer au paramètre suivant.

Vous configurerez au moyen de stratégies de groupes les aspects suivants :

   •  Tous les utilisateurs de votre domaine auront le même arrière-plan de bureau (de votre
     choix)
   •  Seuls les administrateurs du domaine auront accès au Panneau de configuration et à
       l’outil Paramètres
   •  Tous les utilisateurs du domaine devront changer leur mot de passe tous les 30 jours,
      leur mot de passe aura 3 caractères minimum et ne sera pas soumis à des critères de
     complexité
   •  Les secrétaires verront automatiquement le partage SERVICES apparaitre dans leur
     explorateur de fichiers
   •  Seul un administrateur de la machine pourra installer ou mettre à jour les pilotes de
     périphériques.
   • Empêcher le redémarrage automatique des postes en cours d’utilisation
   •  Lors de recherches Windows, ne pas rechercher sur Internet
   •  Bloquer la remontée d’erreurs à Microsoft

   8. Administration de l'infrastructure "depuis sa chaise"

Les éléments de votre infrastructure étant en salle serveur sécurisée, toutes les manipulations
d'administration de serveurs seront effectuées depuis le poste client Windows 10.

•   Installer le service SSH-Server sur votre serveur Debian. Pouvez-vous vous connecter en
    ssh depuis votre Client Windows ? En cas d'échec, faites le nécessaires pour que cela
    soit fonctionnel.

•  Configurer le service bureau à distance sur les serveurs Windows. Seuls les membres du
   service informatique pourront ouvrir une session sur les serveurs. Faire des tests de
   connexions à l'aide de votre client RDP du client Windows 10.

•   Sur le client Windows 10, afficher la liste des "Fonctionnalités facultatives" disponible

•  Pour plus de productivité, rechercher puis installer les outils RSAT (Outils d’administration
  de serveur distant) du "Gestionnaire de serveur" et de gestion des rôles ADDS, DHCP et
  DNS sur votre client Windows 10.

•  Lancer l'outil Gestionnaire de serveur et faire en sorte de pouvoir gérer vos serveurs
   Windows depuis cette console
