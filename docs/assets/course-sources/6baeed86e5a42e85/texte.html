Le DNS et les mises à jour
Démonstration 03 du module 06


 Cette démonstration décrit les différentes étapes relatives à la configuration des mises à jour sur
 un serveur DNS

Déroulement


    •  Ouvrir la console MMC du service DNS.

Ouvrir la fenêtre Outils d’administration puis cliquer sur la ligne DNS (1).





    •  Mise en place de l’enregistrement automatique des hôtes

Lors de  la  configuration des  zones dans  la précédente  démonstration,  l’enregistrement
automatique des hôtes n’a pas été activé.

Pour ce faire, faire droit sur la zone directe (2), puis cliquer sur le menu Propriétés (3). Sélectionner
la ligne Non sécurisé et sécurisé (4). De base, dans le contexte de domaine Active Directory, les
zones seront créées et les enregistrements d’hôtes seront automatiques.

    •  Une autre manière de forcer l’enregistrement d’un hôte.

Installer une VM cliente étant sur le même sous-réseau que le serveur DNS et avec comme serveur
DNS préféré, le serveur DNS sur lequel vous travailler dans cette démonstration.

Ouvrir une invite de commande en tant qu’administrateur sur le poste et client et indiquer la
commande ipconfig /registerdns





    •  Activer le transfert de zone

Installer une VM serveur étant sur le même sous-réseau que le serveur DNS. Installer le service DNS.





Sur le premier serveur DNS, faire un clic droit sur la zone directe (1), puis sur le menu Propriétés (2).
Cliquer sur l’onglet Transferts de zone (3). Dans cette démonstration, le second serveur DNS sera
utilisé. Cocher le bouton radio Uniquement vers les serveurs suivants (4). Cliquer sur le bouton
Modifier (5). Indiquer l’adresse du second serveur DNS (6), puis cliquer sur le bouton OK (7).

    •  Configuration du transfert de zone sur le second serveur

Faire un clic droit sur la ligne Zones de recherche directes (1) puis sur le menu Nouvelle zone… (2).
Cocher le bouton radio Zone secondaire (3), puis cliquer sur le bouton Suivant (4). Indiquer le nom
de la zone que vous souhaitez « copier » (5), puis cliquer sur le bouton Suivant (6). Indiquer l’adresse
IP (7) du serveur maître (ici le premier serveur DNS), puis cliquer sur le bouton Suivant (8).

    •   Vérification du transfert de zone

Se positionner sur la nouvelle zone créée (1). L’ensemble des enregistrements doivent être présents
(2). En cas d’ajout de nouveaux enregistrements, ces derniers seront automatiquement ajoutés sur
cette zone secondaire.
