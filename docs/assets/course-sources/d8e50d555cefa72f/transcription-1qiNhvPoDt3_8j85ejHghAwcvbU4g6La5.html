Les liens

TP du Module 05 – Utiliser des fichiers sous Linux

Avant de démarrer ce TP, il convient d’avoir suivi les vidéos du module 5 et d’avoir
effectué le TP précédent.

Durée estimée

45 à 60 minutes

Proposition de solution

Dans le module que vous venez de parcourir, vous trouverez les commandes nécessaires
pour répondre aux questions.

1. Créez un lien physique du fichier Edition vers le fichier edition1.txt, vérifiez que vous
pouvez afficher son contenu. 

ln Edition edition1.txt 
 
cat edition1.txt

2. Créez un lien symbolique du fichier edition1.txt vers le fichier /tmp/stagxx/edition2.txt,
vérifiez que vous pouvez afficher son contenu. 

mkdir /tmp/stag30 
 
ln -s /home/user30/edition1.txt /tmp/stag30/edition2.txt 
 
cat /tmp/stag30/edition2.txt

3. Créez un lien physique du fichier edition1.txt vers le fichier edition3.txt, vérifiez que
vous pouvez afficher son contenu. 

ln edition1.txt edition3.txt

4. Affichez avec la commande ls les caractéristiques de ces 4 fichiers en mettant en
évidence les différences. 

ls -l edition* Edition /tmp/stag30/edition2.txt

5. Supprimez le fichier edition1.txt, pouvez-vous afficher le contenu de edition2.txt et
edition3.txt ? 

rm edition1.txt 
 
cat /tmp/stag30/edition2.txt 
 
cat: /tmp/stag30/edition2.txt: Aucun fichier ou dossier de ce type 
 
cat edition3.txt
