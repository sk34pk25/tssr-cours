  Pour aller plus loin
  S’authentifier avec PowerShell

            • Pour des raisons de sécurité, nous travaillerons avec des comptes possédant
          des privilèges réduits.

            • Cela peut être problématique pour la réalisation de certaines actions.

            • Afin de contourner cette problématique, il est possible de lancer le script
          avec un compte utilisateur, puis demander une authentification à son
          lancement.
