Recherches et regex
TP du Module 06 – Fichiers et dossiers sous Linux


 Avant de démarrer ce TP,  il convient d’avoir suivi les vidéos du module 6 et d’avoir
 effectué le TP précédent.


           Durée estimée

           45 à 60 minutes

Énoncé

Dans le module que vous venez de parcourir, vous trouverez les commandes nécessaires
pour répondre aux questions.

    1. Recherchez toutes les lignes contenant Dupont dans le fichier Edition.





    2. Recherchez toutes les lignes contenant dupont quelle que soit la casse dans le
        fichier Edition.
