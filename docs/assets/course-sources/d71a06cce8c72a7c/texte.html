Utilisation de Word

TP du Module 02 – Notions de base sur Word

Avant de démarrer ce TP, il convient d’avoir suivi les vidéos du module 2.

Durée estimée

60 à 90 minutes

Énoncé

Objectifs :

•
Mettre en forme un document Word

Prérequis :

•

•
