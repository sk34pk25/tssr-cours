Ouverture de votre nom de domaine
•  Connectez-vous sur https://www.ovh.com/auth

Si vous possédez déjà un compte OVH, connectez-vous. Dans le cas contraire, créez votre
compte et renseignez les informations demandées.





•  Dans le bandeau supérieur, cliquez sur Web Cloud.

Ouverture de votre tenant Microsoft 365
•  Afin d’ouvrir votre tenant, tapez microsoft 365  trial tenant dans votre moteur de
   recherche et cliquez sur Office 365 Trial Tenant.





•  Entrez votre adresse mail. Si besoin, cliquez ensuite sur Configurer le compte.





•  Renseignez les informations demandées. Indiquez un numéro de téléphone valide,  il

•  Ajoutez maintenant le nom de domaine souscrit préalablement chez OVH.





•  Nous allons maintenant ajouter les enregistrements TXT afin de confirmer auprès de
   Microsoft que nous possédons bien ce nom de domaine.





•  Basculez maintenant vers votre compte OVH. Vous pouvez tout de suite annuler le
   renouvellement automatique de votre nom de domaine, vous évitant une mauvaise
    surprise de facturation à échéance de celui-ci.

•  Basculez en Renouvellement manuel, validez et confirmez cette action. Retournez sur le
   tableau de bord et vérifiez que le renouvellement est bien passé en manuel.





•  Accédez maintenant à votre zone DNS publique.
