Les LGPO

TP du Module 13 – Les stratégies de groupe local

Durée estimée

1 heure

Solution

•
Sur Win10-XX, à l'aide des consoles appropriées appliquez les consignes suivantes : 

o Pour augmenter le niveau de sécurité d'accès aux ressources de votre VM,

tous les utilisateurs devront utiliser un mot de passe avec les caractéristiques
suivantes 

o Longueur minimale : 7 caractères 
o 3 mots de passe seront conservés dans l'historique 
o Il devra respecter les exigences de complexité

Rechercher > secpol.msc

Nœud Stratégies de comptes

Nœud Stratégie de mot de passe

Double clic sur Longueur minimale du mot de passe : 7 caractères > OK

Double clic sur Conserver l'historique des mots de passe : 3 mots de passe mémorisés > OK

Double clic sur Le mot de passe doit respecter les exigences de complexité : Activé

Pour comprendre les exigences de complexité > onglet Expliquer

Fermez la session actuelle puis faites des tests "grandeurs réelles" avec des utilisateurs
standard.

Tentez de changer le mot de passe d'un utilisateur standard (CTRL+ALT+SUPPR > Modifier un
mot de passe) et vérifiez si les contraintes de sécurité que vous avez configurées ci-dessus
fonctionnent.

•
Créez une GPO non-administrateurs

Rechercher > mmc

Ajouter le composant logiciel enfichable éditeur d'objet de stratégie de groupe
