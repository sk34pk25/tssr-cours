Enchaînements conditionnels
Solutions - TP1 du Module 06 - Les caractères spéciaux du Shell



A partir de l’analyse des besoins, réaliser un script Shell permettant d’y répondre

Dans les étapes d’élaboration du script, il faudra commencer par vérifier si un nom a été saisi directement
après le fichier de script lors de son exécution. S’il y a bien un seul argument, le conserver durablement dans
une variable, si plus d’un : sortie du script. S’il n’y en a aucun, le script doit le demander et le stocker dans une
variable.

Ensuite, si le nom est ‘root’, le script doit afficher une interdiction et sortir du script. Sinon pour tout autre nom
doit afficher un message de bienvenue.


Les variables réservées sont ici utilisées : $# pour le nombre d’arguments fournis lors du lancement du script et
$1 pour le 1er argument fourni (cf module sur variables réservées)


    •   Créer et éditer un nouveau fichier script, par exemple, nommé script_M6TP1.sh

vim script_M6TP1.sh


    •  Y ajouter les lignes suivantes :

#! /bin/bash

# M6 - Solution du TP1

# Utilisation : ./script_M6TP1.sh  <id utilisateur>

#Déclaration des variables

rouge=’\033[1;31m’

vert=’\033[1;32m’

noir=’\033[0m’

# Etapes de vérification de saisie d’un nom d’utilisateur

[ $# -eq 1 ] && name=$1 # Si 1 argument alors stockage de sa val. dans ‘name’

[ $# -gt 1 ] && echo -e "$rouge Le nombre d'arguments est invalide !$noir" && exit 1 #
Si plusieurs arguments => sortie

[ $# -eq 0 ] && read -p "Veuillez saisir votre nom d'utilisateur : " name # Si 0
argument fourni, invite de saisie

# Si le nom saisi est ‘root’, interdiction en rouge + sortie

[[ $name = root ]] && echo -e "$rouge Interdit de se connecter en $name $noir" && exit
2
