Installation du système d’exploitation Windows 10

Installation

• Prérequis
• Processeurs : 1 GHz
• RAM : 1Go pour système 32bits / 2Go pour système 64bits
• Espace disque : 16Go pour système 32bits / 32Go pour système 64bits

• Le 64 bits, c'est quoi ?
• Adaptation du système d'exploitation aux évolutions des composants

•
Meilleures performances
• Prise en compte native de plus de 4Go de mémoire vive
• Meilleure protection du système

•
Nécessite des pilotes signés

Installation du système d’exploitation Windows 10

Installation

• Un fichier source commun à tous les supports d'installation : "install.wim"
• DVD
• Clé USB
• Image ISO
• Partage réseau et serveur de déploiement
• … tout support amorçable pouvant contenir le fichier "install.wim"
• Un mini-système d'exploitation est requis pour installer Windows
• OS léger pour installer et/ou réparer Windows
• Disponible dans le fichier boot.wim du support d'installation
