Synthèse — Module 1 : Les systèmes d’exploitation, Windows 10 et le modèle OSI (V2)

1. Introduction aux systèmes d’exploitation (OS)

Un système d’exploitation (Operating System — OS) est un ensemble de programmes qui gère les ressources matérielles d’un ordinateur et fournit aux applications des services pour fonctionner.

Composants principaux d’un OS

  • Noyau (Kernel) : cœur du système gérant le processeur (CPU), la mémoire vive (RAM) et la communication matérielle.
  • Interpréteur de commandes (Shell / CLI) : interface en ligne de commande permettant à l’utilisateur ou aux scripts de donner des instructions.
  • Interface graphique (GUI) : environnement visuel facilitant l’interaction utilisateur.
  • Système de fichiers (File System) : organisation et structuration des données sur le stockage.

2. Évolution, modèle WaaS et éditions de Windows 10

Windows as a Service (WaaS)

Microsoft met à jour Windows 10 de manière continue à travers le modèle WaaS : - Feature Updates : mises à jour majeures de fonctionnalités diffusées deux fois par an, canal semi-annuel. - Quality Updates : patchs de sécurité et correctifs distribués mensuellement, Patch Tuesday. - Windows Insider : programme de bêta-test pour essayer les builds en avant-première.

3. Modèle OSI et communication réseau

Le modèle OSI (Open Systems Interconnection) comporte 7 couches théoriques définissant les étapes de la communication réseau.

N° Couche Unité de données (PDU) Protocoles / équipements
7 Application Données HTTP, HTTPS, FTP, SMTP, DNS, DHCP
6 Présentation Données SSL/TLS, ASCII, JPEG
5 Session Données NetBIOS, RPC
4 Transport Segment TCP, UDP ; ports 80, 443, 22, 53

Modèle OSI — suite

N° Couche Unité de données (PDU) Protocoles / équipements
3 Réseau Paquet IP (IPv4/IPv6), ICMP, ARP, routeurs
2 Liaison de données Trame Ethernet, Wi-Fi, commutateurs (switches), MAC
1 Physique Bits Câbles RJ45, fibre optique, signal radio

4. Commandes réseau de base

:: Afficher la configuration réseau complète
ipconfig /all

:: Tester la connectivité vers la passerelle
ping 192.168.1.1

:: Tracer la route vers un serveur distant
tracert google.com

:: Résoudre un nom de domaine via le DNS
nslookup domaine-du-laboratoire.example
