Comment définir un système d’exploitation ?

Un système d’exploitation […] ou Operating System (OS) est un logiciel qui […] pilote les dispositifs matériels et reçoit des instructions de l’utilisateur ou d’autres logiciels (ou applications). […]

Le schéma associe Utilisateur, Logiciel, Système d’exploitation et Ressources matérielles : CPU, RAM, stockage, réseau.

Sources citées dans le support : - https://www.futura-sciences.com/tech/definitions/informatique-systeme-exploitation-11820/ - https://www.journaldunet.fr/web-tech/dictionnaire-du-webmastering/1203371-systeme-d-exploitation-definition-traduction-et-acteurs/

Quelles sont ses fonctions principales ?

  • Gérer les processeurs et la mémoire vive.
  • Optimiser l’exécution des applications en leur attribuant les ressources nécessaires.
  • Fournir des informations sur le bon fonctionnement de l’ordinateur.
  • Utiliser les périphériques dans les meilleures conditions.
  • Protéger l’accès aux ressources.

De quoi est-il composé ?

  • Un noyau (kernel).
  • Un interpréteur de commandes (CLI ou shell).
  • Une interface graphique (GUI), facultative.
  • Un système de fichiers (file system).

Sources citées pour les fonctions et la composition : - https://www.futura-sciences.com/tech/definitions/informatique-systeme-exploitation-11820/ - https://www.journaldunet.fr/web-tech/dictionnaire-du-webmastering/1203371-systeme-d-exploitation-definition-traduction-et-acteurs/

WaaS — Windows as a Service

Vocabulaire Définition du support
Windows Insider Communauté d’utilisateurs bêta-testeurs de Windows 10.
Build Version de Windows 10 identifiée par un numéro, par exemple 1903 pour mars 2019 ; propose son lot de fonctionnalités ; support de 18 mois.
Feature updates Mise à disposition d’une nouvelle build ; deux par an, majeure au printemps et mineure à l’automne.
Quality updates Mise à jour de qualité : patch de sécurité et correctifs de bogues ; tous les deuxièmes mardis du mois, le Patch Tuesday.

Windows 10 et ses éditions

Famille Professionnelle Entreprise
Destinée exclusivement à un usage domestique. Cortana, bureaux supplémentaires, OneDrive, Edge… Intégration à une infrastructure Microsoft : jonction au domaine, traitement des GPO, chiffrement EFS, BitLocker et BitLocker To Go, démarrage natif sur VHD. Fonctions supplémentaires représentées : AppLocker, Windows To Go, DirectAccess, BranchCache.
