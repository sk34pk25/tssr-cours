# TP 01 — Enchaînements conditionnels

## Objectif

Créer un dossier demandé à l’utilisateur, y créer `fic_M5TP1.txt`, écrire un texte dans ce fichier, l’afficher et différencier par couleur les messages relatifs au dossier et au fichier.

## Prérequis cités

Les modules 1 à 5 sont cités dans l’énoncé. Les fichiers d’exercice et tout script de départ ne sont pas fournis dans les sources Drive M05.

## Activités

1. Préparer les variables de scénario `fic`, `bleu`, `vert`, `noir` et `dossier`.
2. Saisir un nom de dossier à créer.
3. Créer le dossier et afficher le message demandé.
4. Créer `fic_M5TP1.txt` dans ce dossier et afficher le message demandé.
5. Écrire le texte demandé dans le fichier.
6. Afficher le contenu du fichier.
7. Utiliser les couleurs de scénario pour différencier les messages relatifs au dossier et au fichier.

Les chemins, messages et la logique restent ceux de l’énoncé ; aucun script autonome n’est ajouté.
