# TP 02 — Script à partir d’un algorithme

## Travail demandé

Créer un script qui :

1. affiche un message d’accueil ;
2. affiche les scripts du répertoire courant ;
3. insère une ligne vide ;
4. affiche la version de Bash ;
5. recherche les emplacements relatifs à Bash ;
6. indique si une mise à jour de Bash est disponible.

L’en-tête interne de l’énoncé renvoie au module 01 — Analyse. Cette référence est conservée comme divergence documentaire : ce TP est physiquement et pédagogiquement rattaché au module 02.

## Preuves à relever

1. Préparez un dossier isolé avec au moins un fichier `.sh` et un nom contenant des espaces.
2. Comparez votre sortie à l’ordre des six étapes, puis essayez une extension sans correspondance.
3. Contrôlez la syntaxe avec `bash -n` avant un éventuel essai. Distinguez la version de Bash, les chemins trouvés et les informations APT locales.
