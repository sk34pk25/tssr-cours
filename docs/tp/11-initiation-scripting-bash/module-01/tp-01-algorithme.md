# TP 01 — Algorithme

## Scénario

Préparer une quantité donnée de café à l’aide d’une cafetière.

## Ressources du scénario

- eau ;
- café ;
- filtre ;
- cafetière ;
- électricité ;
- nombre de tasses `n`.

## Travail demandé

Produire un pseudo-code puis un organigramme qui permettent :

1. de vérifier la présence des ressources ;
2. de terminer lorsqu’une ressource manque ;
3. d’initialiser `d=0` ;
4. d’ajouter une dose d’eau et de café tant que `d` n’atteint pas `n` ;
5. d’incrémenter `d` ;
6. d’allumer la cafetière.

Les vidéos du module 1 et le TP précédent sont cités comme prérequis documentaires, mais ils ne font pas partie des sources M01 disponibles.
