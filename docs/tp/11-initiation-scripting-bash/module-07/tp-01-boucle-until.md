# Énoncé — TP 01 — Boucle `until`

La source mentionne les vidéos M01 à M06, non fournies dans Drive M07.

## Partie 1 — Analyser vendredi 13

Consultez le code de `13.sh` dans le cours original de cette page. Recopiez-le dans un fichier texte de votre machine virtuelle GNU/Linux avec des fins de ligne LF. Le support cite `scp` et WinSCP pour le transfert. Rendez le script exécutable dans le laboratoire et expliquez les zones `<A COMPLETER>` après observation. Précisez l’utilité, les arguments attendus, la progression de la boucle et le classement final.

## Partie 2 — Années bissextiles

Créer `script_M7TP1.sh` afin de déterminer, pour une plage d'années fournie en deux arguments, le nombre d'années bissextiles et les années exactes. L'exemple documentaire `./script_M7TP1.sh 2026 2029` affiche 2028. La source demande de s'inspirer de `13.sh`, de `until`, de `cal` et de l'incrémentation d'un compteur.
