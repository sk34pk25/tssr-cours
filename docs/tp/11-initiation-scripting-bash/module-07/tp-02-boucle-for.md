# Énoncé — TP 02 — Boucle `for`

La source mentionne les vidéos M01 à M07, non fournies dans Drive M07.

Créer `script_M7TP2.sh` pour un répertoire fourni en argument. Le script compte les fichiers selon leurs extensions : un seul argument est requis ; zéro ou plusieurs arguments doivent afficher la syntaxe puis arrêter le script ; les extensions sont inscrites une par ligne dans un fichier externe ; celles qui ne sont pas référencées ne sont pas prises en compte.

L'exemple documentaire pour `/tmp` affiche 20 fichiers, dont 6 `.sh` et 4 `.txt`. Les fichiers de test et le fichier externe ne sont pas fournis dans Drive M07.
