# Module 04 — Atelier n°2 : découverte d’Hyper-V

Ce module comporte **un seul atelier**, d’une durée estimée de **1 heure**.
L’objectif est la mise en place et la découverte de l’hyperviseur Microsoft Hyper-V
et de ses menus de configuration.

## Préparation

Suivre les prérequis M04 et disposer de la VM Windows Server 2019 créée au module 2.
Le laboratoire installe Hyper-V dans cette VM, hébergée par VMware Workstation.
Les noms des machines et les chemins dépendant du poste sont neutralisés ici ; les
paramètres matériels de l’énoncé restent ceux de son scénario.

Les PDF n’incluent ni ISO Windows Server 2019, ni VM prête à importer, ni disque
virtuel de laboratoire. Aucun téléchargement de remplacement n’est inventé.

## Parcours de l’atelier

- [Énoncé de l’atelier unique](tp-01-hyper-v.md).
- [Correction et limites de la solution fournie](correction-tp-01.md).

l’arrêt des machines ont un effet sur le laboratoire : vérifier la VM concernée
avant chaque manipulation. Aucune commande n’a été exécutée lors de cette restitution.
