# Module 02 — Atelier 1 : VMware Workstation

## Situation de travail

Le module comporte un seul atelier : **Atelier n°1 — Installation VMware Workstation**.
Son objectif est de déployer une machine virtuelle Windows Server 2019 dans le contexte
de laboratoire décrit par les sources.

- **Durée source :** 1 heure.
- **Prérequis source :** une machine physique de laboratoire sous Windows Server 2019 ;
  l’adressage IP relève du service DHCP du contexte de formation.
- **Résultat attendu :** une VM configurée selon le scénario, installée, nommée, arrêtée
  puis accompagnée de son snapshot final.

## Ressources et limites du laboratoire

L’atelier mentionne une image ISO Windows Server 2019, un partage de distribution,
VMware Workstation 16 et VMware Tools. Ces éléments ne sont pas fournis dans le dossier
Drive M02 : ils restent des ressources de laboratoire référencées mais absentes.

Les noms de VM, de machine, de partage, de serveur, les chemins locaux, les identifiants
et les mots de passe sont propres au laboratoire et sont neutralisés dans les pages web.

## Attention aux actions à impact

Les opérations décrites créent et configurent une VM de laboratoire, puis installent un
système invité, VMware Tools et un snapshot. Elles ne doivent pas être reproduites sur
un environnement réel sans cadre de formation adapté.
