# Module 06 — Atelier n°4 : gestion réseau

Un atelier d’une heure, issu des PDF du module :

- [Énoncé adapté](tp-01.md)
- [Correction documentaire](correction-tp-01.md)
- [Cours du module](../../../modules/13-virtualisation-serveurs/module-06.md)

Prérequis : deux hyperviseurs ESXi fonctionnels et la VM de l’atelier n°3.
L’atelier distingue gestion, réseau des VM et stockage/vMotion. Les noms et adresses
du laboratoire sont neutralisés. Aucun fichier binaire ni script n’est fourni ici.

**NEEDS_REVIEW :** la solution montre une terminaison forcée des VM, contrairement
à l’arrêt propre demandé. Elle cite le module 5 dans son bandeau ; l’énoncé cite
le module 6. Les deux demandent l’atelier n°3 réalisé.

Provenance A : énoncé et solution M06 du Drive TSSR en lecture seule ; B : adaptation
web fidèle. Aucune action de laboratoire exécutée et aucun atelier supplémentaire.
