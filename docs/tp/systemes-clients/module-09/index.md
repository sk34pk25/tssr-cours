# TP — Module 09 — Les pilotes et les imprimantes

## Scénario

Ce TP de **1 heure** s'appuie sur une machine Windows 10 de laboratoire et une seconde machine nommée Discovery. Il vise à consulter les pilotes, observer le pilote graphique, contrôler les imprimantes disponibles, produire un PDF de test, connecter une imprimante partagée puis interroger une imprimante avec PowerShell.

## Prérequis et environnement

- une VM `Win10-XX` et une VM Discovery ;
- une imprimante partagée et les pilotes associés ;
- les droits nécessaires fournis pour le laboratoire.

Ces ressources de laboratoire sont mentionnées dans les documents source mais **ne sont pas fournies dans le dossier Drive M09 live**. N'inventez ni machine, ni pilote, ni partage de remplacement.

## Objectifs

- exporter les informations détaillées et de signature des pilotes au format CSV ;
- consulter les informations du pilote graphique avec l'interface Windows ;
- configurer Microsoft Print to PDF et vérifier le document produit ;
- connecter et contrôler l'imprimante partagée indiquée par le scénario ;
- relever les propriétés demandées d'une imprimante avec PowerShell.

## Parcours du TP

1. [Énoncé](enonces.md) — consignes et valeurs du scénario.
2. Réaliser les activités dans l'ordre, en conservant les observations demandées.
3. [Correction](corrections.md) — méthode et contrôles après une tentative complète.

## Livrables et contrôles

Le TP demande des exports CSV sur les pilotes, un contrôle du pilote graphique, une page de test PDF et des informations sur l'imprimante interrogée. Les valeurs de matériels, de machines, de partage et de réseau sont des valeurs du laboratoire source.
