# TP — Module 02 — Installation du système d’exploitation Windows 10

## Objectif du laboratoire

Le TP demande de créer une machine virtuelle Windows 10 avec VMware Workstation, d’effectuer son installation et sa première configuration, puis d’importer une machine virtuelle existante au format OVA.

## Parcours

1. Lire l’[énoncé](enonces.md) avant toute manipulation.
2. Identifier les ressources réellement disponibles et celles qui manquent dans le Drive M02.
3. Réaliser les étapes du laboratoire et conserver les livrables demandés.
4. Vérifier les résultats avant de consulter la [correction](corrections.md).

## Ressources du laboratoire

Le fichier historique `Lisez-moi.txt` indique que certains éléments devaient être téléchargés depuis une ressource externe. Ils ne sont pas disponibles dans le Drive M02 actuel :

- l’image ISO de Windows 10 ;
- l’archive `Discovery.ova` ;
- l’archive multi-partie dont le premier fichier est en `.zip.001` ;
- le script de laboratoire mentionné dans le scénario Discovery.

Ces absences ne modifient pas les consignes du TP ; elles empêchent seulement de prétendre que les fichiers sont fournis localement.
