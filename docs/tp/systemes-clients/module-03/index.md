# TP — Module 03 — Interagir avec Windows 10

Les cinq activités ci-dessous reprennent les scénarios TSSR du module. Les environnements, comptes et ressources de laboratoire évoqués dans les PDF sont fournis dans le cadre de la formation ; aucune ressource de laboratoire n’est distribuée depuis cette page.

| Activité | Objectif pédagogique | Durée source |
|---|---|---|
| Prise en main de l’interface graphique | Repérer et personnaliser des éléments de l’interface, puis utiliser une console MMC. | 30 min |
| Prise en main de la CMD | Utiliser l’aide, naviguer et manipuler des fichiers dans l’invite de commandes. | 1 h |
| Premiers pas avec PowerShell | Découvrir la console, les cmdlets, les alias et les chemins. | 30 min |
| Manipuler l’aide de PowerShell | Utiliser l’aide complète, les exemples et les rubriques de concepts. | 1 h |
| Devenir autonome avec PowerShell | Chercher une cmdlet, examiner ses propriétés et produire les résultats demandés. | 1 h 30 |

## Déroulé

1. Lire l’[énoncé](enonces.md) de l’activité intégralement.
2. Réaliser les manipulations dans l’environnement de formation prévu.
3. Vérifier les résultats explicitement demandés.
4. Consulter la [correction](corrections.md) après une tentative complète.

Les énoncés et les corrections restent volontairement séparés.
