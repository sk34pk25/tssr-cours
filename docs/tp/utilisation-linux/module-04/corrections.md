# Correction — TP1 : Fichiers et dossiers

| Question / besoin | Commande fournie par la solution |
|---|---|
| Position dans l’arborescence | `pwd` |
| Fichiers et répertoires présents | `ls -A` |
| Créer le fichier vide demandé | `touch MonPremierFichier` |
| Permissions et propriétaire du fichier | `ls -l MonPremierFichier` |
| Fichiers `.conf` de `/etc` | `ls /etc/*.conf` |
| Caractéristiques de `/tmp` sans son contenu | `ls -ld /tmp` |

Les explications restent limitées aux commandes et aux observations présentes dans la solution source. Les résultats affichés varient selon l’environnement utilisé.
