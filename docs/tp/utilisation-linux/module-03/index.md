# TP01 — Module 03 — Premières commandes

**Sources originales (A) :** énoncé et solution `M03TP01 - Premières Commandes` TSSR.
**Présentation du portail (B) :** organisation des informations explicitement présentes dans les deux documents.

## Objectifs

Le TP demande de changer un mot de passe et de vérifier une nouvelle connexion, puis de relever des informations sur la session, les utilisateurs connectés, les identifiants, l’heure, la date et des calendriers.

## Durée

**45 à 60 minutes** selon l’énoncé et la solution.

## Prérequis attestés

- avoir suivi les vidéos du module 3 ;
- avoir effectué le TP précédent.

Les sources disponibles ne décrivent pas d’environnement de laboratoire, de machine virtuelle ou de ressource téléchargeable supplémentaire.

## Déroulement et vérifications

- [Énoncé du TP01](enonces.md) : les neuf questions à réaliser ;
- [Correction du TP01](corrections.md) : les commandes proposées et les observations associées ;
- après le changement de mot de passe, fermer puis rouvrir la session ;
- relever les informations réellement affichées pour les questions de session, d’identifiants, de date et de calendrier.
