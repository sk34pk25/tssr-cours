# TP — Module 07 : Utilisation de Vi

## TP unique — Modifier le fichier `Edition`

**Durée indicative :** 45 à 60 minutes.

### Objectifs

- Ouvrir `Edition` avec `vi`.
- Rechercher et modifier les occurrences demandées dans le scénario.
- Employer les commandes globales, la commande externe et les réglages documentés.

### Prérequis et ressources mentionnés

L'énoncé renvoie aux vidéos du module 7, au TP précédent et au fichier `Edition`.
Ces éléments sont des prérequis du scénario ; ils ne sont pas disponibles comme
ressources lisibles dans le dossier Drive M07 live.

### Vérifications

Les activités demandent d'observer les recherches, les modifications de `Edition`,
la copie de ligne, les substitutions, puis l'enregistrement avec `:wq`.
