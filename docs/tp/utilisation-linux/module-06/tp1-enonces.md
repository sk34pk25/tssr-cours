# Énoncé — TP01 — Recherches et regex

## Préparer l’atelier

Le support demande de suivre les vidéos du module 06 et de faire le TP précédent. Utiliser le fichier `Edition` du laboratoire et effectuer les copies dans le répertoire personnel du compte d’exercice.

**Durée estimée dans le support**

45 à 60 minutes.

## Activité 1

Rechercher les lignes contenant Dupont dans Edition.

## Activité 2

Rechercher dupont quelle que soit la casse.

## Activité 3

Afficher toutes les lignes non vides.

## Activité 4

Lister les fichiers contenant localhost directement dans /etc, sans sous-répertoires.

## Activité 5

Rechercher les fichiers standards commençant par ho à partir de /etc.

## Activité 6

Rechercher tous les répertoires depuis le répertoire personnel.

## Activité 7

Trouver les fichiers standards de son répertoire personnel terminés par txt et en faire une copie .save.

## Livrables et vérifications

| Contrôle | Trace attendue |
| --- | --- |
| Texte | Comparer les résultats des recherches avec et sans distinction de casse, puis observer l’effet du filtre sur les lignes vides. |
| Parcours | Distinguer les résultats directs sous `/etc` du parcours récursif. Vérifier les répertoires affichés depuis `$HOME`. |
| Copies | Associer chaque copie `.save` à un fichier source qui existe toujours. |
