# TP — Module 05 — Lire des fichiers et gérer les liens

## Objectif du laboratoire

Produire un fichier de texte et expliquer ce qui reste lisible après la suppression d’un nom.

## Parcours

1. Ouvrir l’énoncé et vérifier les prérequis.
2. Réaliser les étapes dans le laboratoire et conserver les observations demandées.
3. Ouvrir la correction et expliquer les écarts avant de reprendre la fiche de révision.
