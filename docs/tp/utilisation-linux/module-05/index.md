# TP — Module 05 : utiliser des fichiers sous Linux

## Prérequis documentaires

Les deux énoncés mentionnent les vidéos du module 5 et le TP précédent. Ces ressources ne sont pas disponibles comme fichiers lisibles dans le dossier Drive M05 audité.

## TP1 — Lire des fichiers

**Durée indicative :** 45 à 60 minutes.

Objectifs attestés : créer deux fichiers avec `cat`, les concaténer, compter les lignes de `/etc/passwd` et afficher deux lignes de `/etc/hosts`.

- [Énoncé TP1](tp1-enonces.md)
- [Correction TP1](tp1-corrections.md)

## TP2 — Les liens

**Durée indicative :** 45 à 60 minutes.

Objectifs attestés : créer et observer des liens physiques et symboliques dans le scénario fourni, puis constater l’effet de la suppression source sur les fichiers du scénario.

- [Énoncé TP2](tp2-enonces.md)
- [Correction TP2](tp2-corrections.md)
