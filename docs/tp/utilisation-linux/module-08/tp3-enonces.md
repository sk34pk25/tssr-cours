# Énoncé — TP03 — Redirections et Alias

## Préparer l’atelier

Le support demande de suivre les vidéos du module 08 et de réaliser les TP proposés. Ouvrir un Bash interactif de laboratoire. Savoir reproduire les quatre opérations du TP Utilisation des systèmes avant de définir les alias.

**Durée estimée dans le support**

30 à 45 minutes.

## Activité 1 — Processus

Lister les processus dont l’affichage se termine par `d`. Stocker le résultat dans `$HOME/process/daemons.txt`.

## Activité 2 — Recherche

Rechercher les fichiers `.conf` à partir de la racine en restant sur le système de fichiers racine. Afficher les chemins à l’écran et les écrire dans `$HOME/resultats/fichiers.conf`.

## Activité 3 — Durée

Mesurer le temps d’exécution de la recherche précédente.

## Activité 4 — Compteur

En une commande, enregistrer dans `$HOME/resultats/compteur.txt` le nombre de fichiers trouvés sans relire `fichiers.conf`. Le fichier doit contenir uniquement ce nombre.

## Activité 5 — Alias

Reproduire les quatre opérations en définissant des alias dans le shell de l’atelier.

## Livrables et vérifications

| Contrôle | Trace attendue |
| --- | --- |
| Alias | Vérifier que les trois noms d’alias sont reconnus dans la session et qu’ils reproduisent les mêmes opérations. |
| Preuves | Relever les fichiers créés et la durée obtenue. Le compteur doit être produit par le flux de recherche. |
