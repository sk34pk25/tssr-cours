# Énoncé — TP03 — Redirections et Alias

**Périmètre :** reprise pratique des consignes du document ; les écarts typographiques sont expliqués dans la correction et le cours.

**Durée indicative :** 30 à 45 minutes.

Les quatre premières demandes du document :

1. Lister tous les processus dont l’affichage se termine par d et enregistrer dans $HOME/process/daemons.txt.
2. Rechercher depuis / les fichiers .conf, sans quitter son système de fichiers, et afficher/enregistrer simultanément les chemins.
3. Mesurer le temps exact de cette exécution.
4. En une commande, enregistrer uniquement le nombre de fichiers trouvés sans relire fichiers.conf.

Puis reproduire ces actions avec les alias demandés.

## Activité 1

Reproduire les quatre actions processus/recherche/durée/comptage avec leurs livrables, puis créer des alias correspondants.
