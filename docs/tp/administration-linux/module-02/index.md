# TP — Module 02 — Installation d’une distribution Debian

**Sources originales (A) :** `M02TP01` et `M02TP02` TSSR, énoncés et solutions d’installation Debian, avec et sans interface graphique.
**Présentation du portail (B) :** organisation des travaux pratiques et liens de navigation.

## Organisation

Le module propose deux parcours distincts. Choisir l’énoncé correspondant à l’environnement demandé, préparer la machine virtuelle, conserver les preuves de vérification, puis consulter la correction seulement après une tentative complète.

## Avant de commencer

- [ ] Utiliser une machine virtuelle ou un environnement de laboratoire.
- [ ] Identifier précisément le disque cible avant le partitionnement.
- [ ] Préparer un point de retour ou un instantané lorsque l’environnement le permet.
- [ ] Lire l’énoncé du parcours choisi en entier avant de démarrer.
