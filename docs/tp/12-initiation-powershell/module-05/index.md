# TP — Module 05 — Outils pour le scripting

## Cadre

- **TP unique :** Outils pour le scripting.
- **Durée estimée par la source :** 1 heure.
- **Objectif :** comprendre les fonctions, les modules et la gestion des erreurs dans un scénario de script PowerShell.

## Prérequis et ressources

Les sources citent les vidéos M05, un environnement de laboratoire et un IDE tel qu’ISE ou Visual Studio Code. Ces ressources ne sont pas fournies comme fichiers autonomes dans le dossier Drive M05. Utilisez uniquement l’environnement et les valeurs fournis par le formateur.

## Activités attestées

1. Concevoir un script qui teste la présence de services et consigne les absences sans les afficher immédiatement.
2. Transformer ce script en fonction paramétrée.
3. Ouvrir puis stocker une session distante dans une variable de laboratoire.
4. Concevoir un traitement d’objets d’annuaire en préservant l’exclusion documentée avant toute action d’impact.
5. Transformer ce traitement en fonction recevant le domaine de laboratoire en paramètre.
6. Configurer le comportement de l’IDE et de la console pour la consignation et l’affichage des erreurs, conformément au scénario source.

## Livrables et vérifications

- lignes de commandes ou script demandés par le TP ;
- fonction paramétrée ;
- session stockée dans une variable ;
- contrôle de l’exclusion protectrice avant toute action à impact ;
- comportement des erreurs vérifié dans l’IDE et la console.

> **Attention :** le scénario inclut des opérations à impact sur des machines de laboratoire. Ne lancez aucune action à distance sans autorisation, valeurs de laboratoire et contrôle préalable.
