# TP — Module 06 — Activités pour aller plus loin

- **Durée estimée :** 4 heures
- **Objectif :** démarrer avec le scripting PowerShell au moyen d'activités de
  lecture, de correction et d'écriture de scripts.

## Pré-requis et ressources citées

Le document source indique d'avoir suivi les vidéos du module 06. Ces vidéos,
les machines, les comptes, les rôles et les fichiers de laboratoire ne sont pas
fournis comme ressources autonomes dans le dossier Drive M06 consulté.

Les scripts de l'archive source sont réservés au laboratoire : ils comportent
des données propres au scénario et des commandes à impact. Ils ne sont ni
publiés ni proposés au téléchargement.

## Activité unique, trois axes

Le TP réunit trois activités dans un même parcours :

1. comprendre et commenter un script fourni ;
2. corriger des erreurs de syntaxe dans un script lié à DNS ;
3. écrire au choix un script de configuration réseau ou un menu de gestion
   d'utilisateurs Active Directory.

## Contrôles attendus

- expliquer l'intention d'un script sans exposer les données de laboratoire ;
- distinguer les formes présentes dans une consigne de celles présentes dans
  une correction ;
- signaler les opérations qui modifient un annuaire, DNS, le système, des
  partages ou des ACL avant toute exécution en laboratoire.

## Provenance et limites

Le TP s'appuie sur l'énoncé TSSR « Activités pour aller plus loin » et sur une
archive de travail consultée uniquement comme source. L'archive, ses scripts et
sa copie DOCX restent `SOURCE_ONLY` ou `SENSITIVE_DO_NOT_PUBLISH` selon leur
contenu.
