# Module 02 — TP 01 : L'objet

## Objectifs

Le TP demande d'observer les propriétés et méthodes d'objets PowerShell, puis
d'utiliser les commandes de gestion de l'objet indiquées par le scénario.

## Durée et prérequis attestés

- Durée estimée : 30 minutes.
- Avoir suivi les vidéos du module 2.
- Utiliser l'environnement de laboratoire fourni par le formateur.

Les vidéos et l'environnement de laboratoire sont cités dans la source, mais
ne sont pas fournis comme ressources séparées dans le dossier Drive M02.

## Parcours

1. [Lire l'énoncé du TP](tp-01-objet.md).
2. Réaliser les observations et manipulations dans l'environnement fourni.
3. [Consulter la correction](correction-tp-01.md) après les vérifications.

## Vérifications attendues

- relever les membres demandés pour les objets de service et d'utilisateur ;
- distinguer les propriétés des méthodes selon les colonnes affichées ;
- vérifier l'état observé du service après l'appel de la méthode demandée ;
- conserver les valeurs propres au laboratoire dans cet environnement, sans
  les recopier dans des livrables publics.
