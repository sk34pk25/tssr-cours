# Module 01 — TP 01 : Premières commandes

## Objectifs

Le TP demande de lancer des commandes PowerShell données et d'analyser les
différences de résultats entre les environnements du scénario.

## Durée et prérequis attestés

- Durée estimée : 2 heures.
- Avoir suivi les vidéos du module 1.
- Disposer de la maquette et de l'environnement de laboratoire fournis par le
  formateur.
- Disposer d'une connexion Internet lorsque le scénario le demande.

Les machines virtuelles, les partages, le module AWS, les fichiers d'aide et le
script de personnalisation cités dans le TP ne sont pas fournis dans le dossier
Drive M01. Ils restent des ressources de laboratoire absentes.

## Parcours

1. [Lire l'énoncé du TP](tp-01-premieres-commandes.md).
2. Réaliser les tâches dans l'environnement fourni par le formateur.
3. [Consulter la correction](correction-tp-01.md) après les vérifications.

## Vérifications attendues

- comparer les résultats observés entre les consoles du scénario ;
- identifier la cmdlet utilisée pour chaque recherche ou affichage demandé ;
- distinguer une observation de laboratoire d'une règle générale ;
- ne pas publier les identifiants ni les accès fournis par l'environnement.
