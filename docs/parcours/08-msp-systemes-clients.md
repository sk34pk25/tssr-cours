# MSP Systèmes clients

Cette étape rassemble les acquis des cours Microsoft et GNU/Linux dans une mise en situation de quatre machines. Prévoir les 4 jours et 3,5 heures annoncés par l’énoncé, puis une vérification des livrables avec le binôme.

1. [Lire le cours et comparer les versions](../modules/08-msp-systemes-clients/module-01-msp-systemes-clients.md).
2. [Réaliser les sept parties de l’énoncé](../tp/msp/module-01/enonces.md).
3. [Comparer avec la solution adaptée et les scripts fournis](../tp/msp/module-01/corrections.md).
4. [Réviser les valeurs, contrôles et pièges](../revision/msp/module-01-msp-systemes-clients.md).

Le résultat attendu associe configuration, procédures, tests d’accès positifs et négatifs, sauvegarde et restauration. Signaler les tests matériels impossibles, notamment l’impression sur les IP fictives. Le mini-quiz du cours et l’autoévaluation de révision permettent de préparer la vérification finale.
